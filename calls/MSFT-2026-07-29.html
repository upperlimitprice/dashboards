QUARTER-OVER-QUARTER CHANGE ANALYSIS

MSFT — 최신 분기 변화 분석

비교 분기: 2025-10-29 · 2026-01-28 · 2026-04-29 · 2026-07-29 · 최신 분기 기준 수치·톤·확신 표현의 변화 (원문 인용 포함)

매출/이익 실적

  • Azure 성장률 재가속: Q1 +40% → Q2 +39% → Q3 +40% → Q4 +43% — 3개 분기 39~40% 박스권에서 벗어나 최신 분기에 뚜렷한 가속. FY26 연간으로는 Azure 매출 $1,000억 돌파(+41%).
  • Microsoft Cloud 규모 확대 지속: Q1 $49.1B(+26%) → Q2 $51.5B(+26%) → Q3 $54.5B(+29%) → Q4 $59.3B(+27%).
  • 총매출 규모 레벨업: Q3 $82.9B → Q4 $900억(+18%)으로 분기 $90B대 첫 진입, FY26 연간 $3,310억(+18%).
  • 일회성 이익 신규 반영: Q4에 Anthropic 투자 평가이익 $32억 등 일회성 항목 합산 EPS +$0.27 효과 (이전 분기에는 OpenAI 지분법 손익만 존재 — Q1 손실 $41억, Q2 평가이익 $100억).
  • 인력 감소 실현: Q3 "FY27 인원수 y/y 감소" 목표 제시 → Q4 실제 인력 -2% 달성 보고.

가이던스

  • Azure 가이던스 대폭 상향: 직전 분기 가이던스 "cc +39~40%" → 최신 FY27 Q1 가이던스 "약 +45%", +5~6%p 상향. 톤도 강화: Q3 "Azure 성장은 CY26 하반기에 상반기 대비 완만한 가속 전망" → Q4 "수요가 공급을 계속 초과하며 H1 성장 가속 예상".
  • FY27 연간 마진 커밋 구체화: Q3 "FY26 연간 영업마진 y/y 약 +1pt" → Q4 "FY27 영업마진 하락은 1%p 미만, FCF 흑자 유지, 두 자릿수 매출·영업이익 성장 지속" — 마진이 소폭 상승에서 소폭 하락으로 방향 전환을 공식화하되 하락 폭에 상한선을 제시.
  • Windows 가이던스 추가 악화: Q3 가이던스 "Windows OEM 10% 후반대 감소" → Q4 가이던스 "-20%대 초반" (부품가 상승·Win10 역기저·재고).

고객사·수주

  • 수주 다변화의 결정적 증거: Q2 "RPO의 약 45%가 OpenAI 관련" → Q4 "분기 RPO 순증은 전액 프런티어 모델 기업 외 고객에서 발생". OpenAI 집중 리스크 논쟁(Q1~Q2 QnA의 핵심 쟁점)이 데이터로 반박됨.
  • ex-OpenAI 수주 재가속: 수주(bookings) OpenAI 제외 기준 Q3 +7% → Q4 +18%. RPO는 $627B(ex-OpenAI +26%) → $678B(+84%, ex-OpenAI +25%).
  • M365 Copilot 시트 가속 지속: Q2 1,500만 → Q3 2,000만 → Q4 3,000만 돌파, 순증 시트 전분기 대비 2배 이상. 대형 계약도 Q3 Accenture 74만 시트에 이어 Q4 신상품 E7으로 EY 40만 시트(E7 역대 최대).
  • GitHub Copilot 수익화 실증: Q3 "6/1부터 사용량 기반 과금으로 전환" (계획) → Q4 "사용량 기반 과금 전환 후 매출이 분기 대비 60% 이상 가속" (결과). 사용자도 Q2 유료 470만 → Q4 전체 5,000만 명.
  • Foundry 급팽창: Q3 "300+ 고객이 연간 1조 토큰 처리 궤도" → Q4 "고객 10만 개, 매출 전년 대비 2배 이상, 1조 토큰 런레이트 고객 수 4배 증가". Agent 365는 Q2 출시 → Q4 "출시 2개월 만에 약 4,000만 에이전트 등록".

수요·리드타임

  • 공급 제약의 성격 변화 — '병목'에서 '즉시 수익화 레버'로: Q1 "용량 제약은 최소 FY26 말까지 지속", Q1 QnA "제약이 없었다면 Azure 성장률은 더 높았을 수 있다" (제약=성장 억제 요인) → Q4 "공급 부족 환경에서는 확보된 효율이 분기 내 즉시 수익화된다. 이 역학이 Q1 가이던스에도 반영돼 있다" (제약=효율 개선이 바로 매출이 되는 구조). 수요 초과 자체는 4개 분기 내내 지속이나, Q4는 "스팟 시장 가격에서도 확인"이라며 외부 증거까지 제시.
  • dock-to-live 단축 가속: Q3 "GPU 도입~가동 시간 ~20% 단축" → Q4 "연중 약 50% 단축". Q4 Azure +43%의 동인으로 CFO가 직접 지목한 실행력 지표.

Capex

  • 절대 규모 확대 지속 + 가이던스 점프: 분기 CapEx $34.9B(Q1) → $37.5B(Q2) → $31.9B(Q3) → $41.0B(Q4), FY27 Q1 가이던스 $500억 이상 — 분기 $50B 시대 첫 제시.
  • 회계 구조 변경 2건 (신규): ① FY27부터 데이터센터·사옥 내용연수 15년→25년 연장, ② 금융리스→운용리스 전환으로 CY2026 CapEx 전망 약 $190B(Q3 제시) → 약 $175B로 조정 — 단, "투자 계획 자체는 불변"이라고 명시. 감가상각 부담 완화로 마진 가시성에 직접 영향.
  • 과잉공급 방어 논리 구체화: Q1 "단기자산 투자는 계약 기간과 수명이 매칭" (원론) → Q4 "수요 환경이 바뀌면 최대 비용 요소를 빠르게 늦출 수 있고, 토지·건물 투자는 타이밍 조절이 가능" + "사이클의 등락은 있어도 구조적 전환(secular shift)은 명확하다" — 다운사이드 시나리오까지 선제 답변하는 수세→공세 전환.

마진·비용

  • 클라우드 총마진율 하락 추세 지속, 단 예상은 상회: 68%(Q1) → 67%(Q2) → 66%(Q3) → 65%(Q4, "예상 상회"). 전사 영업마진도 49% → 47% → 46% → 45%.
  • 자체 모델(MAI) 비용 절감 효과 대폭 확대: Q3 "Transcribe-1에서 GPU 효율 +67%, Image-2에서 최대 +260%" → Q4 "MAI 모델로 Dynamics GPU 비용 89% 절감", "MAI-Cyber-1-Flash가 작업의 90%를 처리하고 10%만 프런티어 모델로 보내 Mythos급 성능을 절반의 비용으로 구현" — 개별 기능 효율에서 제품 단위 COGS 구조 개선으로 격상.
  • ROI 확신 톤 강화: Q1 (버블 우려 질문에) "감가상각과 매출이 정렬된다" (방어적 설명) → Q4 "계산 방식이 바뀐 건 아니며, TAM 확장과 마진 레버에 대한 확신이 커졌다는 점이 핵심" (명시적 확신 상향 선언).

신제품·기술

  • '하네스-모델 분리' 멀티모델 아키텍처의 전사 전략 격상: Q3에서 Copilot 설명 중 일부로 언급("멀티모델 하네스를 모델과 분리하고") → Q4 "하네스(컨텍스트·메모리·액션)를 모델과 분리하는 멀티모델 아키텍처를 전사 전략으로 제시 — 모든 모델은 대체 가능". 단일 모델 의존을 "비용뿐 아니라 리질리언스 리스크(모델의 거부·장애)"로 규정한 것도 신규 프레임.
  • seat+consumption 전환의 실증 단계 진입: Q3 "비즈니스 모델이 '시트당'에서 시트+소비 모델로 전환 중" (방향 제시) → Q4 "라이선스 구매→사용까지 걸리는 시간이 수개월에서 며칠로 단축", GitHub 사용량 과금 후 매출 60%+ 가속 (수치로 입증).
  • 신규 발표: 통합 상품 E7(Agent 365 포함), 보안 멀티에이전트 Project Perception(소비 기반 과금 예정), MAI-Code-1-Flash·MAI-Cyber-1-Flash 등 자체 모델 라인업.

리스크 언급

  • Xbox — 경고에서 공식 리셋으로: Q2 "게임 사업 손상차손(impairment) 반영" → Q3 "품질·핵심 팬 중심의 기본기 재정비 국면" → Q4 "감액·구조조정을 포함한 사업 리셋 진행, FY27 성장 복귀 목표" — 리스크를 인정하되 턴어라운드 시점을 처음으로 명시.
  • 부품가(메모리) 리스크 — 변동성 경고에서 가격 전가 전략으로: Q2 "메모리 가격 상승이 PC 시장, 온프레미스 서버, CapEx에 변동성 요인으로 작용할 수 있다고 경고" → Q4 "부품가 상승은 업계 공통이며, 효율 개선으로 고객 가치를 지키되 신규 계약에는 가격을 반영한다" — 수동적 리스크에서 관리 가능한 운영 변수로 재규정. 다만 실제 타격은 Windows OEM 가이던스 악화(-10%대 후반 → -20%대 초반)로 확대 중.
  • OpenAI 집중 리스크 — 쟁점에서 소멸로: Q1~Q2 QnA마다 집중도 질문 등장(Q2 "RPO의 45%가 OpenAI") → Q4에서는 해당 질문 자체가 사라지고 "분기 순증 전액 비(非)프런티어 고객" 데이터로 대체.

종합 인사이트

최신 분기는 AI 투자 사이클의 "증명 국면 진입"을 보여준다. 3개 분기 내내 방어하던 논점들 — OpenAI 집중, CapEx 대비 ROI, 소비 모델 전환 — 이 Q4에서 각각 데이터(RPO 순증 전액 비프런티어 고객, GitHub 매출 60% 가속, Azure +43%→가이던스 +45%)로 입증되며, 경영진 화법도 "감가상각과 매출이 정렬된다"는 수세적 설명에서 "확신이 커졌다", "구조적 전환은 명확하다"는 공세적 선언으로 이동했다. 특히 Azure 가이던스를 +39~40%에서 +45%로 올리면서 분기 CapEx $50B+를 제시한 것은, 공급 제약이 성장 억제 요인이 아니라 "효율 개선이 분기 내 즉시 수익화되는" 판매자 우위 시장임을 회사가 확신한다는 신호다. 다만 내용연수 15년→25년 연장과 리스 재분류는 투자 계획 불변에도 회계상 마진·CapEx 숫자를 유리하게 만드는 변경이므로, FY27 "영업마진 하락 1%p 미만" 커밋의 질을 해석할 때 할인해서 봐야 한다. 잔존 리스크는 부품가 상승의 소비자 부문 전이(Windows OEM -20%대 가이던스), 클라우드 총마진율의 분기당 ~1%p 지속 하락, 그리고 수요 초과 전제가 꺾일 경우 $175B 규모 CapEx의 하방 경직성이다 — 확신 수준은 높으나, 그 확신 자체가 수요 영속성이라는 단일 가정에 집중돼 있다.
