QUARTER-OVER-QUARTER CHANGE ANALYSIS

AMZN — 최신 분기 변화 분석

비교 분기: 2026-02-05 · 2026-04-29 · 2026-07-30 · 2026-10-29 · 최신 분기 기준 수치·톤·확신 표현의 변화 (원문 인용 포함)

매출/이익 실적

  • AWS 성장률 6분기 연속 가속, 약 5년 만의 최고치: 24%(FY25Q4) → 28%(Q1) → 36.7%(Q2) → 39.3%(Q3). 분기 매출 $35.6B → $37.6B → $42.2B → $46.0B, 연환산 런레이트 $142B → $150B → $169B → $184B
  • 전사 영업이익률 사상 최고치 재경신: Q1 13.1%("역대 최고") → Q2 13.7%(275억/2,006억) → Q3 13.9% "사상 최고치", 영업이익 $23.9B → $27.5B → $28.1B (+61% YoY)
  • 헤드라인 매출 성장은 둔화로 보이나 Prime Day 이동 착시: 전사 +17%(Q1) → +20% FX중립(Q2) → +13% FX중립(Q3). 북미 +16%(Q2) → +6%(Q3), 단 "Prime Day의 2분기 이동 효과 제외 시 리테일 성장률은 약 400bp 높았을 것"
  • 광고 성장 일시 둔화: $19.8B +26%(Q2) → $19.6B +12%(Q3) — "Prime Day 이동으로 약 850bp의 성장률 역풍", "4분기에는 10%대 후반 성장 복귀" 전망
  • AWS 순증폭은 둔화: 전분기比 +$46억(Q2, 역대 최대) → +$38억(Q3). 경영진 해명: "분기별 용량 추가량은 균등하지 않음"

가이던스

  • Q4 가이던스가 분기 매출 레벨을 크게 점프: 직전 Q3 가이던스 매출 $197B~$202B → Q4 가이던스 $240B~$247B (홀리데이 시즌 포함), 영업이익 가이던스 $22.5B~$26.5B → $28.5B~$33.5B
  • 중기 성장 가이던스가 처음으로 구체화: Q2 "AWS를 궁극적으로 연 1조 달러 매출 사업으로 성장시킬 수 있다" → Q3 "2027년과 2028년 각각 40% 이상 성장"하고 "5~10년 내 연매출 1조 달러 사업" — '궁극적으로'라는 막연한 표현이 연도별 수치와 기한(5~10년)으로 바뀜. 근거도 "대형 용량(수백 MW~GW급)은 사전 예약되므로 2027~2029년까지 가시성 확보"로 명시

고객사·수주

  • 백로그 가속 누적: $244B(FY25Q4, +40% YoY) → $364B(Q1) → $496B(Q2) → $578B(Q3, 세 자릿수 % YoY). 4개 분기 만에 2.4배
  • Bedrock이 '제품'에서 '차세대 핵심 사업'으로 격상: Q1 "연환산 수십억 달러 사업" 수준 언급 → Q3 "AWS 역사상 가장 빠르게 성장하는 수십억 달러 규모 서비스", 포춘500 지출 약 7배·토큰 사용량 약 17배 YoY, "Bedrock이 EC2 급 규모 서비스가 될 수 있음"
  • 자체 칩 수주 급증: Q1 "Trainium 매출 커밋먼트 누적 $225B+" → Q3 "매출 약정은 각각(Graviton·Trainium) 20배 이상 증가"
  • 모델 라인업 확대: Q1 OpenAI 모델 추가 → Q3 OpenAI·Kimi·GLM 등 중국계 오픈모델까지 추가, "향후 2~3년 내 6~8개 모델이 대등한 수준이 될 것"

수요·리드타임

  • 수요 가시성 기간이 길어짐: Q2 "2027년 용량 대부분이 이미 예약됐고 2028년 예약도 상당" → Q3 "향후 8~10분기에 걸쳐 대규모 용량이 예정", "2027~2029년까지 가시성 확보" — 예약 가시성이 2028년 → 2029년으로 연장
  • 수요 성격의 질적 전환 확인: FY25Q4에는 바벨 구조의 중간(기업 프로덕션 워크로드)이 "장기적으로" 올 것이라는 전망이었으나, Q3에는 "추론(inference)이 이미 AWS AI 매출의 절반 이상"이라고 현재형으로 확인 — AI 수요가 학습 중심에서 추론(반복 매출) 중심으로 넘어가는 중

Capex

  • 연간 전망 상향 후 유지, 그러나 2027년 추가 증액 예고: FY25Q4 "2026년 약 $2,000억" → Q2 "$2,200억으로 상향(메모리 가격 반영)" → Q3 "약 $2,200억 유지, 2027년은 '의미 있게 더 증가' 예상"
  • 분기 집행 속도 급증: Q1 $43.2B → Q2 $53.1B → Q3 $75.9B (한 분기 만에 +43%)
  • ROIC 서술의 변화: FY25Q4 "강한 ROIC를 확신"(정성적) → Q3 "CapEx 손익분기 도달 시점은 계속 단축(좌측 이동) 중" + "투자 규모는 크지만 자체 조달 가능" — 자금조달 우려에 선제 대응하는 표현이 새로 등장 (Q2에는 "올해 채권 발행을 했고... 오늘 공유할 내용은 없음"으로 유보적이었음)

마진·비용

  • AWS 마진이 한 단계 올라선 뒤 소폭 반락: 35%(FY25Q4) → 37.8%(Q1) → 39%(Q2) → 38.7%(Q3) — 여전히 FY25Q4 대비 +370bp
  • 마진 방어 논리가 구조화됨: Q2 "규율 있는 효율성 개선·용량 최적화·고정비 관리의 결과이며 변동은 있을 것" → Q3는 정량 근거 제시: "데이터센터를 네오클라우드로 쓰면 자가/장기 리스 대비 영업마진이 약 3,500bp 불리한데, AWS는 대부분 자가·장기 리스에 자체 칩까지 사용해 구조적 비용 우위"
  • 마진 희석 요인을 처음 명시적으로 인정: Q3 "AI 매출 비중 확대(코어 대비 낮은 마진)와 메모리 등 부품 가격이 변동 요인" — Q2까지는 "AI 사업은 과거 코어 사업과 유사하거나 약간 앞선 마진 궤도"라며 희석 우려를 반박하는 쪽이었음
  • 리테일 비용 효율은 지속: "4년 연속 유닛당 서비스 비용(cost to serve) 절감 궤도", 로봇 100만 대 이상 운영

신제품·기술

  • Trainium 외판이 '검토'에서 '확정 일정'으로: Q1 "향후 2년 내 가능성 높으나... 할당 균형을 봐야 함" → Q2 "적극 논의 중이며 향후 실제로 할 가능성 상당" → Q3 "2027년 말 AWS 외부 판매 개시 예정" — 3개 분기에 걸쳐 조동사가 사라지고 날짜가 박힘
  • 광고에 AI 통합 플랫폼 신규 출시: Q3 "AI 기반 통합 플랫폼 Amazon Ads Agent 출시" (이전 분기는 Rufus 스폰서 프롬프트 등 부분 기능 수준)
  • Leo 회계 처리 변경: Q3 "Leo 관련 비용은 당초 예상보다 늦은 2027년 1분기부터 자본화 시작, 4분기까지는 대부분 비용 처리" — FY25Q4·Q1의 "YoY 약 $10억 비용 증가" 부담이 2027년부터 손익에서 덜어짐

리스크 언급

  • 부품 가격 리스크의 위치 변화: Q1 "지난해 중반 조기 포착해 전략적 공급사와 협력, 현재 용량 제약은 없음"(방어적 안심) → Q2 CapEx $200B→$220B 상향의 직접 원인으로 등장 → Q3 AWS 마진의 "변동 요인"으로 재차 명시 — 운영 리스크에서 비용·마진 리스크로 성격이 이동
  • 운송비 인플레 신규 경고: Q3 "유가·운임 인플레이션은 4분기에 3분기보다 다소 높을 것(FBA 유류 할증료로 일부만 상쇄)"
  • AWS 순증폭 둔화에 대한 방어적 톤 등장: Q2까지는 "역대 최대 증가폭" 자랑 일변도 → Q3 "$1,840억 런레이트에서 39.3% 성장은 이례적 수준이며, 분기별 용량 추가량은 균등하지 않음" — 성장률 기대치 관리성 발언이 처음 나옴

종합 인사이트

최신 분기(FY2026 Q3)의 핵심 변화는 AWS AI 사이클이 '약속'에서 '숫자'로 전환됐다는 점이다. 백로그 $244B→$578B(4개 분기 만에 2.4배), 추론이 AI 매출의 절반 이상, Trainium 외판 일정 확정, 그리고 "2027~2028년 각각 40%+ 성장"이라는 이례적으로 구체적인 중기 가이던스까지 — 경영진의 확신 수준은 4개 분기 중 가장 높고, 선예약된 용량이 이를 뒷받침하므로 2027~2029년 매출 가시성은 상당히 신뢰할 만하다. 다만 처음으로 AI 매출 믹스가 코어 대비 저마진임을 인정했고 메모리·운임 인플레를 반복 경고한 것은, 39% 전후의 AWS 마진이 고점권일 수 있다는 신호다. 리스크는 (1) 분기 CapEx가 $76B까지 치솟은 상태에서 2027년 추가 증액이 예고되어 FCF 압박이 커지는 점, (2) AWS 순증폭이 전분기 대비 줄며 공급 타이밍에 따른 분기 변동성이 커진 점, (3) 40%+ 가이던스 자체가 미달 시 큰 디레이팅 트리거가 될 수 있다는 점이다. 종합하면 업황은 명확한 상방 가속 국면이고 회사의 구조적 우위(자가 데이터센터+자체 칩)도 강화 중이나, 투자 판단의 초점은 "수요가 있느냐"에서 "마진과 자본효율이 버티느냐"로 옮겨가는 분기다.
