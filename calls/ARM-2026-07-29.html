QUARTER-OVER-QUARTER CHANGE ANALYSIS

ARM — 최신 분기 변화 분석

비교 분기: 2025-11-05 · 2026-02-04 · 2026-05-06 · 2026-07-29 · 최신 분기 기준 수치·톤·확신 표현의 변화 (원문 인용 포함)

종합 인사이트

  • 업황 방향: 데이터센터 CPU TAM 전망이 3월 $1,000억 → 업계 추정 최대 $2,200억+로 급상향, 에이전틱 추론 수요가 CPU 성장 견인 — 상향 사이클 심화 중임
  • 회사 상황: 로열티 YoY 성장률이 +11%(Q4) → +22%(Q1)로 회복, 전분기 MediaTek 역기저 둔화를 벗어나 데이터센터 2배+ 성장이 주력으로 자리잡음
  • 확신 수준: AGI CPU 수요가 $20억 → "$20억 초과"로, $10억 초과 공급 달성 자신감이 "지난 90일간 상승"했다며 자체 실리콘 사업에 대한 톤이 한층 공격적으로 전환됨
  • 리스크 재평가: 스마트폰 메모리 충격이 "저가(v8 이하) 중심"(Q3) → "중·상위 티어까지 약세 확산"(Q1)으로 당초 예상보다 확대, 연간 로열티 전망을 ~20%에서 high teens로 하향 시사함
  • 비용 레버리지: OpEx 증가율이 +37%(Q3)·+30%(Q4) → +18%(Q1)로 급둔화, 영업이익률 +200bp YoY 개선으로 투자 피크를 지나 레버리지 국면 진입 시사함

매출/이익 실적

  • 로열티 성장률 회복: Q4 $6.71억(+11%) → Q1 $7.15억(+22% YoY) — 전분기 "전년 MediaTek 램프의 높은 기저로 둔화"가 Q1 "Q1부터 ~20% 성장 복귀 전망" 예고대로 실현.
  • 매출 YoY 가속: Q4 $14.9억(+20%) → Q1 $12.9억(+22% YoY) — 분기 절대액은 계절성으로 감소하나 YoY 성장률은 상승.
  • 라이선스 정상화: Q4 $8.19억(+29%, 분기 사상 최대) → Q1 $5.74억(+23% YoY) — Q4 라이선스 피크(하반기 60/상반기 40 비중 설명대로) 후 정상 레벨로 회귀.
  • 영업이익률: Q4 ~49% → Q1 ~41%(+200bp YoY) — 라이선스 피크 소멸로 QoQ 하락하나 전년 대비로는 개선.
  • EPS: Q4 $0.60(사상 최대) → Q1 $0.45(+29% YoY), 가이던스 상단 초과.
  • FCF 신규 부각: Q1에 분기 $6.65억 / TTM $14억을 명시 — 직전 분기들에선 전면에 내세우지 않던 지표.

가이던스

  • 연간 로열티 전망 하향: Q4 FY27 "로열티 ~20% 성장 전망" → Q1 "기존 약 20% → 스마트폰 약세 반영 시 high teens 수준으로 하향 시사(클라우드 AI 초과성과가 일부/전부 상쇄 가능)".
  • 차기 분기 매출: Q4가 제시한 Q1 가이드 $12.6억(+20%) → 실적 $12.9억(+22%)로 상회. 신규 Q2 가이드 $13.8억 ±$5,000만(+22% YoY), OpEx ~$7.8억, EPS $0.47 ±$0.04.
  • 차기 분기 로열티/라이선스 믹스 역전: Q4→Q1 가이드에선 로열티·라이선스 모두 ~+20%였으나, Q2 가이드는 라이선스 +약 30% / 로열티 +low teens로 라이선스 주도로 전환(로열티 메모리 약세 반영).
  • AGI CPU 수요·자신감: Q4 "$20억+이나 공급 확보 중이어서 매출 전망 $10억 유지" → Q1 "수요 $20억 초과, $10억 초과 달성에 대한 자신감이 지난 90일간 상승"으로 톤 강화. 상세는 Q3 실적 때 제공 예정.
  • AGI CPU 마진 신규 공시: Q1에 1세대 GM high 30%~low 40%대, 수년 내 50% 목표 처음 수치화. 실리콘 매출 10% 도달 시 별도 라인 분리 공시 FY28 예상 명시.

고객사·수주

  • AGI CPU 고객 확산: Q4 "Meta 리드 파트너" → Q1 "미국·중국 다수 신규 고객 추가, 초기 제품은 이미 복수 고객에 납품". Oracle OCI가 신규 고객으로 추가 언급.
  • Qualcomm 신규 진입: Q1에 "Qualcomm도 Arm 기반 데이터센터 CPU(Dragonfly C1000) 진출 발표" — 직전 분기들엔 없던 신규 하이퍼스케일러급 수요.
  • NVIDIA Vera 양산화: Q3 "88코어" → Q4 "256 CPU 전용 랙" → Q1 "양산 돌입(x86 대비 CPU 성능 +50%, 전력효율 2배)"로 단계 진전.
  • Google Axion 용도 확장: Q4 "TPU 8t/8i + Axion" → Q1 "Axion이 TPU 호스트 CPU로 채택"으로 가속기 연계 구체화.
  • AWS Graviton5 물량: Q3 "192코어" 스펙 중심 → Q1 "수천만 코어 배치 계획"으로 볼륨 가시화.

수요·리드타임

  • Neoverse 누적 출하 가속: Q2 "10억 개" → Q1 "15억 코어 돌파 — 첫 10억에 6년, 최근 5억은 9개월"로 채택 속도 급가속 명시.
  • x86 추월 데이터포인트 신규: Q1에 "IDC 기준 Arm 기반 가속 서버 플랫폼 지출이 최근 2개 분기 만에 약 2배로 증가하며 x86 플랫폼을 추월" — 직전 분기들엔 없던 외부 검증 지표.
  • 데이터센터 CPU TAM 상향: Q4 "2030년까지 $1,000억+" → Q1 "3월 제시한 $1,000억이 보수적이었을 가능성 — 업계 추정은 최대 $2,000억+($2,200억)까지 상향".
  • 공급 제약 전면화: Q1 QnA에서 "메모리·테스트장비·기판·TSMC 웨이퍼 전부 극도로 타이트 — 자체 팹 보유 경쟁사도 수요를 못 맞추는 상황", 다만 "캘린더 '28~'29부터 웨이퍼·메모리 캐파 70~100% 확대 전망"으로 중기 완화 경로 제시.

마진·비용

  • OpEx 증가율 급둔화: Q3 $7.16억(+37%) → Q4 $7.34억(+30%) → Q1 $7.33억(+18% YoY) — R&D 투자 피크 통과 신호.
  • 향후 OpEx 가이드 톤 완화: Q4 "분기별 수 % 순증" → Q1 "mid-single-digit % QoQ 증가"로 구체화, "Q1 절감분은 유지".
  • 가이던스 하회 폭 확대: Q4 OpEx "약 $1,000만 하회" → Q1 "약 $2,700만 하회(툴·에뮬레이션 비용 타이밍 요인, 연간 계획은 유지)".
  • AGI CPU 마진 구조 공개: Q4 "내년 영업이익 흑자 가정 가능, '31년 칩 사업 ~35%" → Q1 "1세대 GM high 30~low 40%, 수년 내 50% 목표(ASIC 외주 내재화 전제)"로 1세대 수치 구체화.

신제품·기술

  • AGI CPU 코어 수 하향 조정: Q4 "AGI CPU 136코어, 향후 256~512코어" → Q1 "현행 128코어, 로드맵(192/256) 공개는 아직 없음, 코어 수 증가는 방향성" — 구체 로드맵 수치가 후퇴.
  • NVLink Fusion 경로 신규 언급: Q1에 "NVLink Fusion을 통해 Arm 계열 CPU를 Rubin 등 커스텀 가속기에 연결하는 경로 존재(현시점 발표 사항 없음)" — 가속기 결합 수단 구체화.
  • 오픈소스 AI 모델 영향 평가: Q1 신규 질의에 "중립~긍정적 — 오픈소스 모델이 소형·효율화되어 엣지로 확산되면 엣지 footprint 큰 Arm에 오히려 유리, 상위 레이어에 agnostic".

리스크 언급

  • 스마트폰 메모리 충격 확산: Q3 "타격은 저가(v8 이하) 중심이고 프리미엄은 보호… 전체 로열티 영향 1~2% 수준" → Q1 "당초 저가 영향 예상과 달리 중·상위 티어까지 약세 확산" — 범위 확대, 연간 로열티 ~20%→high teens 하향으로 연결.
  • FY31 $150억 목표 방어 톤: Q4 단정적 제시 → Q1 "3월 수치는 당시 공급 전망 기반이며 변경 없음… 다만 TAM 상향으로 제시 수치가 보수적이었을 수 있음, 내부 목표는 외부 제시치보다 높음"으로 상방 여지 강조.
  • '골든 스크류'(단일 부품) 리스크 신규 질의: Q1에 "단일 부품 미확보로 전체가 막히는 리스크는 없음 — 단일 실패 지점 부재"로 공급망 집중 우려를 선제 차단.
