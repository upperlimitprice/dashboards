QUARTER-OVER-QUARTER CHANGE ANALYSIS

TSEM — 최신 분기 변화 분석

비교 분기: 2025-11-10 · 2026-02-11 · 2026-05-13 · 2026-08-04 · 최신 분기 기준 수치·톤·확신 표현의 변화 (원문 인용 포함)

매출/이익 실적

  • 매출 사상 최대 경신 지속, 성장률 가속: 3Q25 $396M(+7% YoY) → 4Q25 $440M(+14%) → 1Q26 $414M(+15%) → 2Q26 $460M(+24% YoY). 최신 분기에서 YoY 성장률이 4개 분기 중 최고.
  • 마진 레벨업: GPM 24%(3Q25) → 27%(1Q26) → 30%(2Q26, 사상 최고). NPM 14%(3Q25) → 18%(4Q25) → 16%(1Q26) → 20%(2Q26). 2Q26은 GPM·OPM·NPM 모두 "회사 최고 기록(일회성 회계 항목 제외)".
  • 증분 이익 전환율 상승: FY25 연간 "증분 매출 $82M 중 약 49%가 순이익" → 2Q26 QoQ 기준 "매출총이익 58%, 영업이익 55%, 순이익 55%". 모델 가정(증분 GPM 59%)에 이미 근접.
  • 톤 변화 — 마진에 대한 확신: 3Q25 "증분 마진은 약 50%를 웃돌 수 있지만, Newport Beach 임대료와 신규 감가상각이 일부를 상쇄합니다"(유보적) → 2Q26 "이번 분기를 앞으로 수년간 이어질 마진 확대의 첫 단계로 보고 있음"(구조적 확신).

가이던스

  • 분기 가이던스 점프: 1Q26 가이던스 $412M → 2Q26 $455M → 3Q26 중간값 $520M(연환산 $2B 이상). QoQ 가이던스 증가폭이 +10%→+13%로 확대. "연초에 예고한 하반기 고성장이 현실화되는 중".
  • 2028 장기 모델 대폭 상향 (예고 → 실행): 2월 모델 매출 $2.84B / 순이익 $750M → 8월 모델 $3.6B / $1.2B (매출 +27%, 순이익 +60%). GPM 목표 39.4% → 45%, NPM 26.4% → 33%.
  • 톤 변화 — 상향 사이클의 연쇄: 1Q26 "모델 상향은 향후 몇 분기 안에 이뤄질 것으로 본다"(가능성 시사) → 2Q26 실제 상향 단행에 더해 "장비 반입 일정이 아직 확정되지 않아 2027년 초중반에 장기 모델을 다시 업데이트할 예정"(차기 상향까지 예고). 상향이 일회성이 아닌 반복 패턴으로 자리잡음.
  • 참고로 3Q25 시점 장기 모델은 매출 $2.7B / 순이익 $500M이었음 — 3개 분기 만에 순이익 목표가 $500M → $750M → $1.2B로 2.4배.

고객사·수주

  • 계약 기반 가시성의 질적 변화: 4Q25 "캐파의 70% 이상이 2028년까지 고객 선수금으로 예약(예약 진행 중 포함)" → 1Q26 "2027년 매출 $1.3B가 계약상 확보, 선수금 약 $290M 수령" → 2Q26 $1.3B 유지하되 "늘어나는 생산능력은 모두 계약된 것은 아니지만 고객 수요로 사실상 소진된(spoken for) 상태". 예약 진행형 → 계약 확정 + 초과수요로 단계 상승.
  • 파트너십 확장: 4Q25 NVIDIA 파트너십 발표(모듈 경유 공급) → 2Q26 신규로 "Marvell과 만든 코히어런트 광모듈 누적 출하는 수백만 개", "IQE와 III-V 에피웨이퍼 장기 공급계약". 공급망 상류(소재)까지 장기계약으로 묶음.
  • 계약 지평 연장: 2Q26 "주요 고객과 2028년까지 장기계약이 있고 그 이후 계약도 논의 중. 차세대(+2~3세대) 공동개발과 독점 계약" — 이전 분기까지는 2027~28년 계약이 논의의 끝이었음.

수요·리드타임

  • SiPho 매출 가속: 4Q25 $95M(연환산 $380M) → 2Q26 연환산 $680M 이상(QoQ +60%, YoY +270%), "4Q26 $1B run-rate가 목표". 3Q25 시점 증설 후 목표였던 "런레이트 $900M 이상"을 이미 넘어서는 목표치.
  • NPO가 전망에서 실체로: 1Q26 "2027년 NPO 수요는 이미 강하다"(전망) → 2Q26 "향후 1년 내 여러 건의 배치가 예정되어 있음", 2027년 SiPho 매출 내 NPO 비중은 "한 자릿수가 아니라 수십 % 수준"(구체적 물량·비중 제시).
  • InP 소재 병목 해소: 1Q26 "InP 원재료 공급이 빠듯하지만 공급망 대응으로 수요를 맞출 수 있다" → 2Q26 "인화인듐 기판 부족은 IQE 계약으로 해소해 공급은 전반적으로 양호함". 유일하게 언급되던 공급측 제약이 제거됨.
  • RF 모바일 바닥 인식 전환: 1Q26 "2026년 연간으로는 감소한다" → 2Q26 "'안정'보다는 성장 국면에 들어선다고 봐야 함", "2027년 중반까지 300mm 웨이퍼 투입이 3배". 다만 당분기 실적 자체는 여전히 부진(300mm RFSOI YoY -14%).

Capex

  • 투자 규모의 단계적 확대가 '팹 신설'로 격상: $350M(연초) → $650M(3Q25) → $920M(4Q25) → 2Q26에는 $920M(집행 50%)에 더해 일본 300mm 듀얼트랙 증설 발표 — Track 1: Arai(옛 Fab 6) 전환, 4Q27 양산 준비(2028 모델 상향의 근거); Track 2: Fab 7 옆 신규 팹으로 일본 300mm 캐파 4배, 장비 가동 4Q28.
  • 구체화된 300mm 전략: 3Q25 "자체(유기적) 방식으로 검토 중. 자세한 내용은 4분기 실적 발표에서 공개할 예정" → 1Q26 METI 보조금 전제 "최대 4배까지 늘릴 계획" → 2Q26 "예산은 승인됐고 내부 현금으로 충당하며 희석은 없음", "SiPho 생산능력은 최소 월 2~2.5만 장 추가". 검토 → 계획 → 승인·착수로 3개 분기 만에 완결.

마진·비용

  • 모델상 마진 구조 상향: 증분 GPM 가정 "약 50%"(3Q25) → 59%(4Q25 모델) → 2028 신모델에서는 목표 GPM 자체가 39% → 45%(증분 기여 67%).
  • 영업 레버리지 명시: 2Q26 신규 언급 — "R&D는 40% 이상 늘리지만 매출 대비 OpEx는 약 7%로 낮아질 전망".
  • 가격 정책의 변화: 3Q25 "올릴 수는 있지만 기회주의적 인상은 하지 않습니다" → 1Q26 200mm BCD 13% 인상 단행("누적된 가격 인하를 바로잡은 것") → 2Q26 "모델의 가장 큰 변수는 웨이퍼 판가. 가격 변동이 거의 100% 마진에 반영되기 때문". 가격이 리스크이자 레버로 전면에 등장.

신제품·기술

  • 400G/lane 변조기: 로드맵 → 시연 → 상업화 레퍼런스: 3Q25 "세 갈래 경로를 함께 개발 중"(경로 탐색) → 1Q26 Coherent와 400G 실리콘 MZM 시연, OpenLight InP 이종집적 시연 → 2Q26에는 이를 경쟁 "차별점"으로 제시("Coherent와 함께 개발한 400G 실리콘 모듈레이터", InnoLight 삽입손실 사례).
  • 패키징 내재화의 수익화: 3Q25 "CPO 자체가 본격 상용화되려면 업계 전반적으로 몇 년이 더 걸릴 것" → 2Q26 die-to-wafer/wafer-to-wafer 본딩 도입, "인화인듐 통합 레이저는 내년에 수천만 달러 매출이 예상되며, 현재 외주인 공정을 내재화할 계획". 패키징이 R&D 항목에서 매출 항목으로 이동.

리스크 언급

  • 리스크의 성격 전환 — 수요·공급 리스크에서 가격 변수로: 4Q25 "메모리 부족·가격 상승은 통제할 수 없는 변수라 우려는 있음. 고객 재고를 면밀히 모니터링" + Intel Fab 11X 조정(mediation) 절차 → 2Q26에는 둘 다 미언급, 남은 변수는 "모델의 가장 큰 변수는 웨이퍼 판가" 하나로 수렴.
  • 실행 리스크 톤 완화: 4Q25 "장비 문제나 공급사 일정 때문에 1~3개월 지연될 수는 있지만 모델은 반드시 달성한다" → 2Q26에는 지연 단서 없이 Track별 일정(4Q27, 4Q28)을 확정적으로 제시. 다만 Track 2는 "장비 반입 일정이 아직 확정되지 않아" 모델 미반영 — 실행 리스크가 사라진 게 아니라 다음 증설로 이월된 상태.

종합 인사이트

4개 분기의 궤적은 'AI 광통신 수혜의 초기 국면'에서 '구조적 성장기업으로의 재정의'로 요약된다. 매 분기 Capex가 상향되고($350M → $920M + 일본 신팹), 장기 순이익 목표가 3개 분기 만에 $500M → $1.2B로 2.4배가 됐으며, 상향 때마다 다음 상향을 예고하는 패턴은 수요가 회사의 공급 계획을 계속 앞지르고 있음을 시사한다. 계약 $1.3B + 선수금 $290M + "spoken for"라는 표현은 2027년까지의 가시성이 포캐스트가 아닌 계약 기반임을 의미해 확신 수준은 매우 높다고 판단한다. 다만 리스크는 분명하다 — 매출의 절반이 RF 인프라(비중 49%) 한 축에 집중되어 AI 데이터센터 투자 사이클 둔화 시 타격이 크고, 회사 스스로 "가격 변동이 거의 100% 마진에 반영"된다고 인정한 만큼 GF·TSMC(COUPE) 등 경쟁 증설이 2027~28년 판가 압력으로 돌아올 수 있으며, 2028 모델의 상당 부분이 아직 짓지 않은 팹(Track 1·2)의 일정 준수에 걸려 있다. 종합하면 업황은 명확한 상승 사이클 중반이고 회사의 실행력도 증명되고 있으나, 밸류에이션 판단 시에는 2028 목표치($3.6B/$1.2B)를 그대로 쓰기보다 증설 지연 1~2분기와 판가 하락 시나리오를 할인해 반영하는 것이 적절하다.
