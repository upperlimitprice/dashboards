QUARTER-OVER-QUARTER CHANGE ANALYSIS

NVO — 최신 분기 변화 분석

비교 분기: 2025-11-05 · 2026-02-04 · 2026-05-06 · 2026-08-05 · 최신 분기 기준 수치·톤·확신 표현의 변화 (원문 인용 포함)

종합 인사이트

  • 업황 방향: GLP-1 시장 여전히 ~40% 고성장 지속, 경구제가 신규(naive 약 80%) 환자 유입시키며 시장 확장 국면 재확인됨
  • 회사 상황: 조정 매출 -4%(Q1)→+7%(Q2) 역성장 탈출, 가이던스 3분기 연속 상향(-5~-13%→0~-6%)으로 턴어라운드 진입함
  • 확신 수준: 상업 부문은 확신 강화("아직 우리를 배제하지 말라") vs R&D는 ZEUS·CagriSema 연속 미스로 방어적 톤 전환됨
  • 리스크 축 이동: '수요·가격' 중심에서 'R&D 파이프라인 실패'로 리스크 무게중심 이동함
  • 비용 체력: 구조조정 1.2만명(-15%) 조기 완수로 영업이익 +11%(CER) 레버리지 확보, 그러나 매출총이익률은 78.2%로 추세적 하락 지속됨
  • 하반기 경계: 세마 LOE(캐나다·브라질)+전년 GTN 역기저로 하반기 약 -5% 역성장 예고됨

매출/이익 실적

  • 매출 역성장 탈출: 조정 매출 -4%(CER) → +7%(CER) ("일회성 제외 시 조정 매출 -4%(CER)" → "2Q26 조정 매출 785억 DKK, +7%(CER)")
  • 영업이익 반전: 조정 영업이익 -6%(CER) → +11%(CER)
  • 미국 턴어라운드: 미국 매출 -11% → +4%
  • IO 가속: IO 매출 +6% → +10%
  • 당뇨 GLP-1 회복: -11% → +2% (미국 과거기간 리베이트 조정 약 20억 DKK 수혜, 약 3/4이 Ozempic)
  • 비만케어 감속: +22% → +16%, IO 비만 +44% → +37%
  • 미국 Wegovy 주사제 신규 공개: (신규) -22%(CER) — "볼륨은 성장했으나 실현가격 하락이 상쇄"

가이던스

  • 매출 가이던스 재상향: -4% ~ -12%(CER) → 0% ~ -6%(CER)
  • 영업이익 가이던스 재상향: -4% ~ -12%(CER) → 0% ~ -6%(CER)
  • 확신 톤 심화: Q1 "매출·영업이익 범위를 1%p 평행 상향 — 이는 자신감의 신호로 해석해 달라" → Q2 "2026년 가이던스 재차 상향" + 2027 복귀 가능성에 "GLP-1 시장이 ~40% 성장 중이고 2Q에 7% 성장을 냈으니 '아직 우리를 배제하지 말라'"
  • 하반기 역성장 명시: Q1엔 없던 경고가 신규 등장 — "하반기는 세마글루타이드 특허만료와 전년 기저효과로 역성장 전망"(-5% 수준 암시)

고객사·수주 (지역 확장·급여)

  • 글로벌 출시 본격화: Q1 "올해 첫 해외 시장 출시를 발표" (점진적 롤아웃) → Q2 영국 출시 3주 만에 "약 30만 명 신규 환자", 노보 비만약 점유율 30%→45%, UAE 경구 시장 약 50%, "9월 독일 출시 예정"
  • Medicare 채널 신규 언급: Q2 "Medicare Bridge 프로그램 ... 초기 처방량에 만족하나 지속성은 더 지켜봐야" — 가이던스엔 보수적 가정 유지

수요·리드타임

  • Wegovy pill 누적 처방: 200만 건+(16주) → 500만 건(6개월), "역대 최강의 GLP-1 볼륨 런칭"
  • 경구 비만약 점유 신규 공개: (신규) "경쟁 경구제 출시에도 미국 경구 비만약 시장의 약 90% 점유"
  • 비만 환자 확장 프레이밍: Q2 신규 — 비만 치료 환자 "전년 대비 약 70% 증가(약 500만 명)"
  • 공급 여력 전환: Q1 "공급이 무제한은 아니지만 ... 재고를 갖췄고" → Q2 신규 API 공장 밸리데이션 완료로 "향후 수년간 특히 Wegovy pill의 미국 외 확장에 대규모 물량 공급 가능"

Capex

  • API 신규 설비 마일스톤 도달: Q4 "주요 API 신규 설비 일부가 올해 가동 예정" → Q2 "첫 공장 첫 라인에서 첫 제품 밸리데이션 완료" — 단, "현재 상업 공급 기여는 매우 낮은 가동률 수준"

마진·비용

  • 매출총이익률 추세 하락: 조정 GM 80.6%(전년 83.5%) → 78.2%(전년 82.7%) — 가격 하락 + 제조 캐파 계약 조정 일회성 약 30억 DKK + 환율
  • self-pay 믹스 악화 신규 공개: 미국 Wegovy 주사제 자가부담 비중 "1년 전 10~15% → 35%로 상승"
  • 구조조정 조기 완수: Q1 "임직원 수 약 1만 명 감소한 약 6.8만 명" → Q2 "인력 약 12,000명(-15%) 감축 완료", "계획 대비 조기 달성 중"

신제품·기술

  • CagriSema 당뇨 톤 반전: Q4/Q1 연속 성공(REIMAGINE 2 A1c -1.91%p/체중 -14.2%; REIMAGINE 1 A1c -1.8%p/체중 -13.8%) → Q2 REIMAGINE 4 head-to-head "체중감량(15.2%)은 tirzepatide 대비 비열등 입증했으나 HbA1c(-1.9%p)는 비열등 미달"
  • ziltivekimab ZEUS 실패: Q1 "ZEUS Phase III 첫 결과는 2026년 3분기 예상" → Q2 "첫 CVOT인 ZEUS 실패(MACE HR 0.99)"
  • Wegovy HD 7.2mg 확장 단계 전환: Q1 미국 전채널 출시 완료 → Q2 "올해 IO의 메인 플레이는 Wegovy 7.2mg 고용량 출시(20개 시장 계획)"

리스크 언급

  • R&D 실패 리스크 전면화: Q1 "R&D 모멘텀" 강조 → Q2 "R&D 실패가 이어지는데 리스크 접근법을 바꿀 것인가" 질문 등장, 경영진 방어 "저위험·고가치와 고위험·고가치의 균형 포트폴리오를 유지"
  • IL-6 가설 의문: Q2 신규 — "ZEUS는 ... IL-6가 캐스케이드의 너무 하류였을 가능성", "염증 타깃 자체를 포기하긴 이르다"
  • 세마 LOE 임박·구체화: Q1 "그룹 기준 낮은 한 자릿수 수준" → Q2 "캐나다·브라질 중심 ... 하반기 개시", "LOE 영향은 내년에 연간화됨"
  • 가격 압력 평가 유지: Q2 "새로운 가격 역학은 없고 연초에 제시한 가격압력 그대로" — 악화가 아닌 믹스 변화로 규정
