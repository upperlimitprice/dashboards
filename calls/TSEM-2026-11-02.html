TSEM — 최신 분기 변화 분석

비교 분기: 2026-02-11 · 2026-05-13 · 2026-08-04 · 2026-11-02 · 최신 분기 기준 수치·톤·확신 표현의 변화 (원문 인용 포함)

종합 인사이트

  • 업황 방향: SiPho 주도 수요가 가속 중, 가이던스 궤적 $412M → $455M → $520M → $600M으로 분기마다 상향 기울기 자체가 커짐
  • 회사 상황: 2월 "매 분기 순차 성장" 목표 단계에서 "회사 역사상 가장 강력한 성장 국면에 진입" 선언 단계로 격상됨
  • 확신 수준: 4Q25 "모델은 반드시 달성" → 3Q26 "달성에 대한 확신이 매우 높은 수준에서만 시장에 제시"로, 목표 상향($3.6B)에도 확신 표현이 더 강해짐
  • 가시성: 캐파 선약 기한이 "2028년까지" → "2029년까지 연장"으로 늘고, CapEx는 "일정보다 앞서" + "1년 내 완전한 ROI" 주장까지 나옴
  • 리스크: 4Q25의 메모리 부족·Intel Fab 11X 분쟁 언급이 사라지고, 2Q의 "가장 큰 변수는 웨이퍼 판가"도 "가격이 견고하고 지속 가능"으로 해소 톤 전환
  • 잠재 부담: Track-2 기여 시점이 "4Q28 장비 설치·가동 목표" → "2029년이 증설 기여 시점"으로 사실상 한 분기 이상 밀린 점은 유일한 후퇴임

TSEM 4개 분기 비교 — 최신 분기(3Q FY2026, 2026-11-02) 변화 분석

매출/이익 실적

  • 매출 가속: 2Q $460M(QoQ +11%, YoY +24%) → 3Q $526M(QoQ +14%, YoY +33%) — 성장률 자체가 분기마다 확대 (1Q YoY +15% → 2Q +24% → 3Q +33%)
  • 순이익률 계단식 상승: 1Q26 16% → 2Q 20% → 3Q 23% (순이익 $65M → $91M → $120M). 1년 전(4Q25) 18% 대비로도 5%p 개선
  • 매출총이익 급증: 2Q $138M(GPM 30%) → 3Q $179M(GPM ~34%, YoY +92%)
  • 증분 마진 상회: 2Q 증분 GPM "58%" → 3Q "~62~65%로 일시적 상회" — 다만 "아직 전체 장비 감가상각이 시작되지 않은 영향(약 65%분만 개시)"이라고 스스로 단서를 달음
  • EPS 2배 이상: 희석 EPS 전년 동기 $0.47 → 3Q $1.05

가이던스

  • 분기 가이던스 점프: 3Q 가이던스 중간값 $520M → 4Q 가이던스 $600M (QoQ +14%, 역대 최대 폭 증액). 연간 2026년 $2.0B, 연말 런레이트 $2.4B 제시
  • 2027년 출발점 신규 제시: 이전 분기들엔 없던 "1분기 계절성 없이 성장 지속, 2026년 1분기 대비 45% 이상 높은 출발" 목표가 새로 등장
  • 장기 모델 궤적: 2월 "$2.84B / 순이익 $750M" → 8월 상향 "$3.6B / $1.2B" → 11월 유지하되, "이미 보수적인 것 아닌가" 질문에 "공격적인 목표이며, 달성에 대한 확신이 매우 높은 수준에서만 시장에 제시한 것"이라고 답해 사실상 추가 상향 여지를 남김 (1Q26 "모델 상향은 향후 몇 분기 안에 이뤄질 것" 발언이 8월에 실제 이행된 흐름)
  • SiPho 런레이트 목표 상향: 4Q25 "4Q26 캐파 5배" → 2Q26 "4Q26 $1B run-rate 목표" → 3Q26 "4분기 SiPho 연환산 런레이트 $1.1B 초과 전망" — 목표치가 달성 전에 계속 올라감

고객사·수주

  • 계약 기한 연장: 2Q "주요 고객과 2028년까지 장기계약" → 3Q "캐파 계약을 2029년까지 연장" ("캐파 계약을 2029년까지 연장한 것이 가시성과 ROI 확신을 높임")
  • NPO 고객 기반 구체화: 2Q "향후 1년 내 여러 건의 배치가 예정" → 3Q "10개 이상의 상위 고객과 NPO 프로토타이핑 진행 중" + "2027년 하반기부터 의미 있는 NPO 출하" + "가까운 시일 내 고객 공동 PR 공개 검토 중"
  • 신규 수주 발표: 3Q에 "Semtech와 대규모 캐파 계약 발표" — 이전 분기엔 없던 명시적 신규 고객 계약
  • 선약 강도 유지·확장: 2Q "늘어나는 생산능력은 … 고객 수요로 사실상 소진된(spoken for) 상태" → 3Q "해당 캐파는 2029년까지 연장된 고객 계약·협상으로 이미 선약(spoken for) 상태" + "발표되는 캐파가 즉시 고객 계약으로 소진되는 상황"

수요·시장 전망

  • SiPho 매출 규모: 2Q 연환산 "$680M 이상"(QoQ +60%) → 3Q 단일 분기 약 $240M(연환산 ~$960M), 2027년 3Q 기준 증설 완료 시 "$2.8B+ 런레이트 가능" 수치 신규 제시
  • NPO 시장관 격상: 2Q "NPO 전환이 다음 성장축" → 3Q "NPO로의 폼팩터 전환이 … 광트랜시버 시장을 2배로 키울 수 있다는 관측" — 시장 자체의 확대 논리로 발전. NPO 콘텐츠도 2Q "콘텐츠 자체는 늘지 않음" → 3Q "NPO는 레인 수 증가로 실리콘 수요가 커지고 신기술일수록 시작 가격도 높음"으로 긍정 쪽 수정
  • RF 모바일 바닥 통과: 2Q "'안정'보다는 성장 국면에 들어선다" → 3Q "일시 부진했으나 회복 궤도 … 2분기에는 RFSOI 사상 최대 출하 전망" + "미발표된 신규 시장을 여는 수준의 획기적 성능 지표 프로그램도 리드 고객과 진행 중"

Capex

  • 집행 가속: $920M 집행률 4Q25 28% → 1Q26 40% → 2Q 50% → 3Q 약 65%, 그리고 처음으로 "일정보다 앞서 진행 중이며 1년 내 완전한 ROI 달성 목표"라는 회수 기간 언급 등장
  • 추가 증설 예고: 3Q 신규 — "200mm 2개 사이트 추가 증설도 곧 발표 예정"
  • Track-2 시점 후퇴: 2Q "장비 설치·가동 목표는 4Q28이고, 2029년 성장으로 바로 이어지게 하는 것이 목표" → 3Q "건설 기간을 감안하면 2029년이 증설 기여 시점이라는 판단. 한 분기 앞당기는 것이 목표이긴 함" — 유일하게 보수화된 항목
  • 재무 체력 소모: 유동비율 4Q25 6.5배 → 1Q 5.6배 → 2Q 4.9배 → 3Q 3.7배 (CapEx 선집행 반영, 다만 자기자본은 $2.9B → $3.2B로 계속 사상 최대)

마진·가격

  • 가격 인상 폭 확대: 1Q26 "200mm BCD 가격을 13% 올렸다"(과거 인하 보정 성격) → 3Q26 "2027년 혼합 ASP 20% 인상 전망" — 보정에서 공세적 인상으로 성격 변화
  • 가격 리스크 톤 반전: 2Q "모델의 가장 큰 변수는 웨이퍼 판가. 가격 변동이 거의 100% 마진에 반영" → 3Q "장기계약에 가격 목표가 포함돼 가격이 견고하고 지속 가능 … NPO는 플러거블보다 높은 시작 가격. 저가 공세 경쟁자는 대개 기술 경쟁력이 없는 경우" — 최대 변수로 꼽던 항목을 통제된 변수로 재정의
  • 증분 GPM 가이드 정착: 2월 모델 "증분 GPM 59%" → 8월 모델 "증분 기여 67%" → 3Q "장기적으로 55~58% 가이드"로 지속가능 수준을 명시 (이번 분기 62~65%는 일시적이라고 선제 디펜스)

신제품·기술

  • 통합 레이저 양산 진입: 2Q "인화인듐 통합 레이저는 내년에 수천만 달러 매출이 예상"(계획) → 3Q "InP 레이저를 SiPho 다이에 통합하는 die-to-wafer 기술 초도 양산 발표"(실행) + "현 모델에 미포함된 추가 업사이드"
  • TFLN 진전: 1Q "TFLN … 양산화 추진(Lightwave Logic, NLM Photonics)" → 3Q "TFLN 기반 400G/레인 차세대 제품도 Tier 1 고객과 전개" — 파트너 개발 단계에서 대형 고객 전개 단계로
  • SiGe 세대 교체: 3Q 신규 — "차세대 H6 SiGe 기술은 이미 양산 적용"
  • 300mm 수율 성숙: 1Q "Fab 7에서 처음 출하한 SiPho 웨이퍼의 수율은 95%"(첫 출하) → 3Q "300mm에서 매우 높은 수율로 양산 출하 중 … NPO 테이프아웃 대부분이 300mm"

리스크 언급

  • 구(舊)리스크 소멸: 4Q25에 있던 "메모리 부족·가격 상승이 핸드셋 물량에 미칠 영향 … 통제할 수 없는 변수라 우려" 및 "Intel Fab 11X … 조정(mediation) 절차 진행 중" 언급이 이후 분기에서 완전히 사라짐; 2Q의 "인화인듐 기판 부족"도 "IQE 계약으로 해소" 이후 재언급 없음
  • 경쟁 인식의 미세 변화: 1Q "현재 Tower가 압도적인 1위이며 이 지위가 바뀔 이유가 없다" → 3Q "급성장 시장이라 복수 플레이어 여지가 있으나 … 고도로 차별화된 높은 점유율 유지에 자신" — 경쟁 진입 자체는 인정하되 점유율 방어 논리를 LTA·공동개발(Gen+2, Gen+3)로 구체화
  • 남은 실행 리스크: Track-2 기여 시점 2029년으로의 순연과 NPO 출하가 "시장 채택 속도에 좌우"된다는 단서가 최신 분기의 사실상 유일한 유보적 표현임
