QUARTER-OVER-QUARTER CHANGE ANALYSIS

AEHR — 최신 분기 변화 분석

비교 분기: 2026-01-08 · 2026-04-07 · 2026-07-14 · 2026-11-02 · 최신 분기 기준 수치·톤·확신 표현의 변화 (원문 인용 포함)

종합 인사이트

  • 업황 방향: AI 번인 수요가 평가 단계에서 양산 램프로 전환됐고, 멀티칩 패키지 열 제어 한계로 웨이퍼레벨 번인의 구조적 수요 확대 국면 진입임
  • 회사 상황: 3개 분기 전 매출 역성장·적자($9.9M, -$1.3M)에서 최신 분기 사상 최대 매출·이익($33.0M, +$9.4M)으로 완전한 변곡점 통과함
  • 확신 수준: 가이던스가 "제공 재개" → "상단 달성 예상" → 범위($130~150M) → 단일값 $150M 상향으로 매 분기 격상, 최신 분기엔 "의도적으로 보수적"이라고까지 언급함
  • 고객 구조: 소수 고객 의존에서 벗어나 "12개 이상 고객"이 대형 양산 수주 잠재력 보유 — 분기 변동성 리스크가 처음으로 '완화' 프레임으로 전환됨
  • 리스크: 공급망(장납기 부품)은 선매입으로 선제 대응 중이나, 사상 최대 기회로 지목된 벤치마크 고객의 양산 채택이 2027년 초 설치·검증 결과에 달려 있음

매출/이익 실적

  • 매출, 역성장에서 사상 최대로: FQ2 $9.9M(YoY -27%) / FQ3 $10.3M(YoY -44%) → FQ1 FY27 $33.0M(YoY +200%, QoQ +75%), 분기 사상 최대. FQ2 "매출은 $9.9M으로 예상보다 부진했습니다" → 최신 "분기 사상 최대치 달성"
  • 흑자 전환 후 이익 급증: Non-GAAP 순손실 -$1.3M(-$0.04) → -$1.5M(-$0.05) → +$3.6M($0.11) → $9.4M($0.28, 전분기 대비 +163%)
  • 매출총이익률 수직 상승: 29.8% → 36.5% → 45% → 48.5% (전년동기 대비 +11%p)
  • 소모품 비중 회복·확대: FQ3 $3.0M(29%) → 최신 $13.5M(41%), 5배 이상 성장. FQ3 "올해 비중이 낮았던 것은 일시적이라는 설명" → 실제로 장기 목표(30%+)를 상회
  • 영업레버리지 입증: Non-GAAP 영업비용 $5.7M → $7.8M(+36% YoY)에 그친 반면 매출은 +200% — 최신 노트에서 "영업레버리지 입증" 명시

가이던스

  • 연간 가이던스 상향·단일화: FY27 $130~150M(FQ4 제시) → $150M 확정 상향(FY26 $50M 대비 +200%). 수익성도 "세전이익률 18~22%" → "순이익률 최소 20%"로 하한 중심 표현으로 강화
  • 톤의 격상: FQ2 "가시성이 개선되면서 가이던스 제공을 재개했습니다" → FQ3 "모두 상단 달성을 예상" → 최신 "맞다, 의도적으로 보수적으로 설정. 공급 제약이 아니며 … 추가 수주가 들어와도 연내 출하 가능"
  • 분기 흐름 전망 강화: FQ4 "3분기는 보합, 4분기는 다시 상승" → 최신 "잔여 3개 분기는 매 분기 점진 증가, 4분기가 연중 최대가 될 가능성"

고객사·수주

  • 수주·잔고 레벨 자체가 변함: 분기 수주 $6.2M → $37.2M → $60.7M → $46.7M(북투빌 1.4); 유효 수주잔고 $18.3M → $50.9M → $100.6M → $109.3M
  • 벤치마크 고객, 평가에서 구매 결정으로: FQ2 "벤치마크는 신규 fine-pitch 고전류 WaferPak으로 진행 중" → FQ3 "클럭 구성에 대한 오해 때문에 … 지연되고 있습니다" → FQ4 "'패키지 레벨보다 낫다'고 평가" → 최신 "FOX XP 웨이퍼레벨 번인 테스트셀 1대 구매 결정 … 회사 역사상 최대 규모의 번인 시스템 기회". 규모 언급도 구체화: "연 100만 유닛당 FOX 시스템 5~10대 … 100만 유닛당 $35~70M"
  • 리드 AI 고객 후속 수주 확대: FQ3 $14M → 최신 $22M 후속 수주(완전자동화 FOX XP + 오토얼라이너 + 풀 세트 컨택터)
  • 하이퍼스케일러, 포캐스트에서 월 양산 출하로: FQ2 "아직 PO 전이며, 출하는 FY27 1분기부터 요청" → FQ4 $41M 사상 최대 주문 → 최신 "월 12대 이상 출하 중", 2번째 AI 프로세서 퀄 완료·"첫 번째 프로세서보다 더 큰 양산 물량 전망"
  • 고객 기반 다변화 명시: 최신 분기에 처음으로 "12개 이상 고객이 대형 양산 수주 잠재력 보유 — 고객·플랫폼 다변화로 분기 변동성 리스크 완화" 언급

수요·리드타임

  • 수요 톤 역전: FQ2 WaferPak 출하 감소로 매출 부진 → 최신 "고객들이 오히려 납기 당겨달라는 상황"
  • 웨이퍼레벨 번인의 구조적 논거 신규 등장: FQ3 "앞으로 웨이퍼레벨로 옮겨가는 흐름이 나타날 것으로 봅니다" → 최신 "열 제어 한계로 패키지레벨 번인이 불가능해지는 추세 → 웨이퍼레벨 번인의 구조적 수요 확대" — 가능성 전망에서 필연 서술로 강화
  • SiC 바닥 탈출: FQ2 "SiC: 계속 부진합니다 … 시스템 수주 예상을 다음 회계연도로 미뤘습니다" → FQ3 "매출 회복 전망은 보수적으로 잡고" → 최신 "SiC는 가동률 풀 상태로 수요 개선", $7M+ 수주 확보·"올해 성장 예상"
  • GaN도 확대: FQ2 결함 이슈로 $2M 출하 지연 → 최신 "최근 6개월간 양산 고객 2곳 추가"

Capex·생산능력

  • 캐파 증설 방식 구체화: FQ3 CM 월 20대+ 추가 계획 발표 → FQ4 Fremont 약 10배 확장 → 최신 "$150M 이상 출하 가능한 인프라 확보", 웨이퍼레벨 사내 조립 공수를 연말까지 "1/3로 축소해 캐파 3배 확대 효과" — 자산경량 기조는 유지
  • 현금 체력 변화: 기말 현금 $31M → $37.1M → $116.5M → $105.1M, 무차입. FQ2~3엔 ATM으로 조달하는 입장($40M 한도 전액 소진)이었으나, 최신 분기 현금 유출(-$3.1M)은 "AI 양산 대비 장납기 부품 선매입 등 운전자본 투자"로 성격이 수세→공세로 전환

마진·비용

  • 마진 지속성에 대한 자신감: FQ2 GPM 29.8%(물량 감소 탓) → 최신 48.5%, 그리고 "FY2027 연간으로는 48.5% ±0.5%p 수준 유지 전망"이라는 연간 커밋 등장
  • 공급망 비용 언급 변화: FQ4 "전원공급장치 가격이 40% 오르는 등 공급망 부담" → 최신 "장납기 부품·얼라이너 선매입으로 버퍼 확보" — 우려 제기에서 대응 완료 서술로

신제품·기술

  • DITC(다이별 온도 제어) 첫 공개: 최신 분기에 WaferPak 통합 ±0.5°C 독립 온도 제어 특허 기술 소개 — "멀티다이 패키지에서 모든 다이를 최적 번인 조건에 맞출 수 있는 유일한 방식", 2027년 초 벤치마크 고객 양산 평가 시스템 탑재 예정
  • HBM 기회 구체화: FQ3 "HBM 업체들과도 논의를 시작" → 최신 "HBM의 로직 베이스 다이는 … 번인 스크리닝이 필요하며 복수 공급사에서 수요 확인"

리스크 언급

  • 분기 변동성 리스크의 프레임 전환: FQ3 "주문 한 건이 $10~20M에 달해 실적이 들쭉날쭉할 수 있다" → 최신 "고객·플랫폼 다변화로 분기 변동성 리스크 완화"
  • 경쟁 이슈 신규 등장과 일축: 최신 분기에 대형 테스트 장비사의 'AI 번인' 신제품 질문이 처음 나왔고, 회사는 "그것은 SLT 계열로 … 진짜 번인과 다름. 패키지레벨 번인 상담에서 SLT 대안은 거론되지 않음. 오히려 Sonoma의 진짜 경쟁자는 자사 FOX 웨이퍼레벨 시스템"이라고 대응 — 외부 경쟁보다 자기잠식을 더 큰 변수로 규정
  • 잔존 리스크: '사상 최대 기회'인 벤치마크 고객 건은 여전히 테스트셀 1대 단계로, "2027년 초 설치 후 1~3월경 데이터 확인 → 캐파 계획 의사결정" — 양산 PO 전환은 미확정 상태
