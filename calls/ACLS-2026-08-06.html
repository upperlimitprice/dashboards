QUARTER-OVER-QUARTER CHANGE ANALYSIS

ACLS — 최신 분기 변화 분석

비교 분기: 2025-11-04 · 2026-02-17 · 2026-05-07 · 2026-08-06 · 최신 분기 기준 수치·톤·확신 표현의 변화 (원문 인용 포함)

종합 인사이트

  • 업황 방향: 파워 사이클이 조정을 끝내고 회복 진입, 전방시장 안정 신호 확인 — 바닥 통과 후 완만한 상향 전환 국면으로 판단함
  • 회사 상황: 연간 가이던스를 "보합"에서 "mid-single digit 성장"으로 상향, 2분기 연속 매출·EPS 예상 상회 — 실적 모멘텀이 턴한 분기임
  • 확신 수준: 지난 분기 "한 분기로는 추세 아니다"던 유보적 태도가 사라지고 연간 전망 공식 상향으로 전환 — 확신이 눈에 띄게 강해짐
  • 리스크: 관세 리스크 언급이 전면에서 사실상 소멸, 중국 비중은 40%→46%로 재반등해 감소 추세가 역전됨
  • 메모리: 2026년 강성장 유지하되 분기 변동성·하반기 보합을 강조, NAND는 여전히 추세 아님으로 선 긋기 지속함

매출/이익 실적

  • 매출 반등: $199M → $215M (예상 상회, 시스템 $126M → $132M, CS&I $73M → $83M)
  • EPS 회복: 희석 EPS $0.72 → $1.06 (단, Q1은 합의금 $5M·EPS -$0.09 반영분 포함)
  • GPM 개선: 40.7% → 42.7% (Q1 가이던스 41% 하회 → Q2 가이던스 43% 소폭 하회, "CS&I 내부 믹스와 예상보다 높은 서비스 비용 때문에 소폭 미달")
  • 수익성 전반 상향: OPM 11.7% → 14.7%, 조정 EBITDA $27.7M(13.9%) → $36M(16.7%)
  • 세율 하락: 14% → 11% ("예상 15%였으나 주식보상 관련 절세 효과 반영")

가이던스

  • 연간 전망 상향(핵심 변화): FY26 "전년 대비 flat" → "mid-single digit 성장" — Q1 원문 "2026년 매출 가이던스 전년 대비 flat을 유지" vs Q2 원문 "기존 '2025년 대비 보합'에서 2026년 매출 mid-single digit 성장으로 바꿨고"
  • 상향 거부 → 상향 단행: Q1 BofA 답변 "1Q 수주는 고무적이지만 한 분기만으로 추세라고 보기는 어렵습니다 … 따라서 연간은 flat" → Q2 "연간 전망을 올렸다"
  • 차기 분기 매출 가이던스 상향: 2Q 가이던스 ~$205M → 3Q 가이던스 ~$230M
  • 차기 분기 EPS 가이던스 상향: 2Q ~$0.90 → 3Q ~$1.11 (2Q 실제 $1.06로 beat)

고객사·수주

  • 수주 소폭 증가: $128M → $131M (수주잔고 $453M → $452M, 대체로 유지)
  • BB율 흐름 연장: Q1 "2분기 연속" 개선 → Q2 "최근 3개 분기 BB율이 약 1배에 가까워졌다"
  • 북미 메모리 고객 진전: Q1 "장비 평가도 마쳤습니다" → Q2 "평가를 마친 뒤 신규 팹용 추가 주문을 냈다"
  • SiC 신규 고객: Q2에 "중국 신규 고객 2곳을 확보", 슈퍼정션용 고에너지 채널링 장비 "여러 고객에게서" 수주

수요·리드타임

  • 파워 국면 전환(톤 변화): Q1 "general mature는 고객의 생산능력 소화가 이어지고 있습니다" / 파워도 디제스천 지속 → Q2 "파워 시장은 조정(digestion)을 끝내고 회복 국면에 들어섰다"
  • 전방시장 표현 변화: Q1 "전방 시장은 회복 중입니다" → Q2 "전방 시장이 안정되고 있다는 신호로 본다"
  • SiC 수주 모멘텀: Q1 "출하는 줄었지만 수주가 강했습니다" → Q2 "수주는 전분기보다 늘었고 상반기 누적으로 최근 2년 평균을 넘었다"
  • 메모리 변동성 강조로 선회: Q1 "2026년 메모리는 강한 성장" → Q2 "분기마다 변동이 크다"·"하반기 메모리 매출은 상반기와 비슷"으로 눈높이 조절, 2027년도 "성장률은 2026년보다 낮을 것"

마진·비용

  • GPM 개선: 40.7% → 42.7% (상기 실적 참조)
  • OpEx 증가: $57.7M → $60M ("실적 호조에 따른 성과급 증가가 주원인")
  • 메모리 마진 코멘트 신규 등장: Q2에서 "메모리 장비 판매의 GPM이 회사 평균보다 낮지만, 이후 고마진 CS&I가 따라오므로 장비 수명 전체로 보면 매력적" — 메모리 비중 확대의 마진 희석 우려에 선제 방어 논리 추가

신제품·기술

  • XEmax 단계 진전: 과거 "PMIC 용도로 XEmax 평가용 장비 출하" → Q2 "Purion XEmax(최대 15MeV)가 선도 파운드리의 PMIC 양산용 평가를 통과"
  • 2nm 소재개질 장비 출하 진행: Q1 "2Q 초에 2nm 양산용 소재개질 장비를 출하" → Q2 "2Q에 1대 출하했고 3Q에도 후속 1대 출하"
  • Purion H6: 출시 단계 넘어 Q2 "High Current에 대한 관심도 커지고 있다"

리스크 언급

  • 관세 리스크 소멸: Q1 "관세 영향은 연간 100bp 미만이지만 1Q에 더 크게 반영된 뒤 점차 줄어들 것" → Q2 노트에는 관세 언급이 사실상 사라짐 (리스크 전면에서 후퇴)
  • 중국 비중 재반등(추세 역전): 46%(FY25 Q3) → 32%(Q4) → 40%(Q1) → 46%(Q2) — "4분기에도 추가로 줄어들 것"이라던 Q3 전망과 달리 비중이 다시 상승
  • NAND 선 긋기 지속·강화: Q1 "NAND는 2026년 전망에 거의 반영하지 않았습니다" → Q2 "NAND는 일부 움직임만 있을 뿐 아직 추세라고 하기 어렵다"
