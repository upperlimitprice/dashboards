QUARTER-OVER-QUARTER CHANGE ANALYSIS

SNPS · Synopsys, Inc. — 최신 분기 변화 분석

비교 분기: 2025-09-09 · 2025-12-10 · 2026-02-25 · 2026-05-27 · 최신 분기 기준 수치·톤·확신 표현의 변화 (원문 인용 포함)

매출/이익 실적

  • 실적 서술이 '미달·해명'에서 '전면 상회'로 전환: Q3 FY25 "분기 실적은 IP 사업 부진으로 기대에 미달" → Q2 FY26 "매출·non-GAAP 영업이익률·EPS 모두 가이던스 상회. AI 주도 수요 강세와 견고한 실행이 배경". 4개 분기 연속 개선 궤적(미달 → Q4 상단 → Q1 상단·EPS 초과 → Q2 전 항목 상회).
  • IP 사업 순차 반등 확인: IP 매출 YoY는 -8%(Q3 FY25) → -8%(Q4) → -6%(Q1) → -6%(Q2)로 유사하나, 전분기 대비로는 Q1 "보합" → Q2 +12% QoQ ($4.07억 → $4.54억). 회사가 처음으로 "IP 사업은 Q1에 바닥을 통과"라고 명시.
  • IP 마진 회복: 조정 영업이익률 20.1%(Q3 FY25) → 16.2%(Q1 FY26) → 24.4%(Q2 FY26).
  • 재무구조 정리 완료 후 주주환원 실행 단계: Q4 "FY26 중 잔여 $25.5억 조기상환 계획" → Q1 "텀론 43억 달러 전액 상환 완료, 자사주 매입 20억 달러 재승인" → Q2 실제 집행($2.5억 ASR + $5,000만 공개시장 매입).

가이던스

  • FY26 가이던스 첫 전면 상향: 매출 $95.6~96.6억(Q4·Q1 유지) → $96.25~97.05억 (사업 호조 +$3,500만, 채널 회계 +$6,000만, Processor IP 매각 -$4,000만).
  • EPS 상향 폭 확대: Non-GAAP EPS $14.32~14.40(Q4) → $14.38~14.46(Q1, 이자비용 감소로 +$0.06) → $14.72~14.80(Q2, 중간값 +$0.34). Q1의 상향이 재무적 요인이었다면 Q2는 사업 호조가 원천.
  • 마진 가이던스 상향: Non-GAAP 영업이익률 중간값 40.5% → 41% (+50bp, "전년 대비 300bp 이상 개선").
  • FCF 상향: 약 $19억 → 약 $20억 (+$1억).
  • 방향성 대비: Q3 FY25는 연간 가이던스를 하향("매출 감소 및 인수 관련 이자·현금 사용으로 기존 전망 대비 하향")했던 것에서 3개 분기 만에 상향 사이클로 완전 반전.

고객사·수주

  • 백로그는 소폭 감소 추세: $101억(Q3 FY25) → $114억(Q4) → $113억(Q1) → $110억(Q2). 회사 설명은 Q1·Q2 동일하게 "갱신 시점에 따른 정상적 등락"이나, 2개 분기 연속 감소는 상향된 가이던스와 대비되는 유일한 역방향 지표.
  • 인터커넥트 IP 수주 지표의 구체화·강화: PCIe 7.0 13건(Q4) → PCIe 설계 수주 40건 이상(Q1) → "PCIe 7.0 IP 90% 이상 수주율(신규 라이선스 18건), UCIe 누적 150건 이상, 업계 최초 HBM4 IP 테스트칩"(Q2). 점유율(90%)이라는 지배력 지표를 처음 제시.
  • 최대 고객(인텔) 서사의 반전: Q3 FY25 "주요 파운드리 고객의 사업 차질… 2025년 회수 기대가 무산" → Q2 FY26 "18A/14A 파이프라인 확대는 IP 사업의 순풍… 가이던스에는 관련 업사이드를 반영하지 않았으며, 수주가 양산으로 전환되면 상방 요인". 악재에서 미반영 옵션 가치로 전환.
  • 신규 이벤트 — 행동주의 주주 등장: Elliott Management와 협력 계약, Jesse Cohn 독립 이사 선임. "추가 수익화 기회와 영업이익률 개선"이 공동 의제로, 이전 분기들에 없던 외부 압력 변수.
  • 에이전틱 AI 고객 확대: Q3 FY25 "약 20개 고객이 Synopsys.ai GenAI 기능을 파일럿" → Q2 FY26 "20개 고객이 25개 이상의 전문 AI 에이전트(프론트엔드·검증·구현·아날로그)를 평가" — 고객 수는 유사하나 대상이 GenAI 보조 기능에서 전문 에이전트 포트폴리오로 진화.

수요·리드타임

  • IP 수요 톤의 결정적 전환 — 가장 큰 변화: Q3 FY25 "IP는 '전환기·부진한 한 해'가 될 것으로 예상… 과거와 같은 계절적 반등을 기대하지 말라" → Q4 "성장 둔화(muted) 전망" → Q1 "순차적 개선 전망" → Q2 "Q1이 바닥이었고 Q2에 +12% 순차 성장을 달성했으며, 남은 분기에도 순차 성장을 지속할 것으로 확신". '전망(expect)'에서 '확신(confident)'으로, 그리고 실적으로 뒷받침되는 서술로 이동.
  • 비AI 시장은 미약한 개선 신호만: Q1 "소비자·자동차·산업용은 완만한 회복 신호에도 여전히 부진" → Q2 "산업·자동차 아날로그 영역의 설계 착수는 여전히 부진. 다만 피지컬 AI와 관련한 아날로그 고객의 관심은 커지고 있음" — 부진 진단은 유지하되 처음으로 전방 관심 증가라는 단서 추가.
  • 하이퍼스케일러 COT 수요가 IP 전략의 중심으로: Q3 FY25에는 하이퍼스케일러 대응이 "리소스 배분 판단 착오"의 원인으로 언급 → Q2 FY26 "하이퍼스케일러의 자체 칩(COT) 전략이 Synopsys IP 가용성에 기반" — 문제였던 수요가 구조적 순풍으로 재정의.

마진·비용

  • 비용 시너지 달성 시점 명시: Q4 "시너지는 10% 인력 감축에 포함… 11월 이미 실행" → Q1 "비용 시너지 3년 차 $4억(1~2년 차로 앞당기는 중)" → Q2 "FY2026 말까지 약정 비용 시너지의 약 절반 달성 예상" — 정성적 '앞당김'에서 정량적 진도율로.
  • 구조조정 뉘앙스 변화: Q3 FY25 "FY2026 말까지 글로벌 인력 약 10% 감축" → Q2 FY26 "10% 감축 약속은 유지하되 비우선 영역을 줄이면서 로드맵·go-to-market 핵심 인력에는 선별 투자 중" — 일괄 감축에서 재배치형으로.
  • 회계 변경: Ansys 채널 매출 총액(gross) 인식 도입 — 매출 +$6,000만이나 "EPS·현금흐름 중립". 가이던스 상향분 해석 시 차감 필요.

신제품·기술

  • 공동 솔루션이 '예정'에서 '시연·상용화 임박'으로: Q3 FY25 "ANSYS 열 사인오프 통합 솔루션은 2026년 상반기 출시 예정" → Q2 FY26 "Multiphysics Fusion 기술이 설계 클로저 최대 3배, 복잡한 아날로그 설계 턴어라운드 최대 2배 단축 효과를 시연 중이며 2026년 하반기 상용화 시작" + 실증 사례("선도 HPC 업체가 멀티피직스 인지 설계-사인오프 통합 솔루션으로 차세대 AI 가속기 테이프아웃 완료, 분기 내 30건 이상의 풀플로우 기술 수주"). 매출 시너지($4억)는 FY2027 발생으로 시점 확정.
  • 에이전틱 AI 과금 모델 구체화: Q4 "에이전틱 AI로 인한 워크플로우 변화에 따른 새 과금 모델"(개념) → Q1 "가치 기반 과금으로 전환할 기회" → Q2 "기존 구독 라이선스에 에이전트 사용량 기반 소비(consumption) 과금을 더하는 '구독+소비' 모델을 고객과 초기 탐색" — 모델 구조가 처음 특정됨.
  • IP 신규 수익모델의 시제 변화: Q3 FY25 "로열티를 포함한 새로운 수익모델을 고객과 논의 중" → Q4 "FY26 내 일부 계약 확보 목표" → Q2 FY26 "신규 비즈니스 모델 계약을 연내 일부 고객과 체결 예정" — 논의→목표→체결 예정으로 단계 상승.
  • 포트폴리오 슬림화 진행: Q1 "ARC 프로세서 IP의 GlobalFoundries 매각" 발표 → Q2 "Processor IP Solutions 사업부 매각 조만간 완료 예정". 9월 30일 Investor Day 신설 예고(수익화 모델 상세 공개 예정).

리스크 언급

  • 중국 리스크가 서사에서 사실상 소멸: Q4 FY25에서는 핵심 이슈("중국은 수출 규제 누적 영향으로 FY25 매출 18% 감소… 규제 대상 고객이 중국 로컬 EDA/IP 대안으로 이탈하는 점유율 이동 발생") → Q1 "역풍 지속" 언급 → Q2 FY26 핵심포인트·QnA 어디에도 중국 언급 없음. 리스크 해소라기보다 가이던스 디리스크("환경 개선 없음을 전제") 이후 관심이 이동한 것으로 해석해야 함.
  • 경영 실책 인정 → 실행력 강조로: Q3 FY25 "악재의 규모를 예측에서 놓친 신호가 있었음을 인정" → Q2 FY26 "견고한 실행(execution)"이 실적 배경으로 반복 강조. 다만 Elliott 참여 자체가 시장이 인식하는 새로운 거버넌스·수익화 압력 리스크의 방증.
  • 매각 관련 규제 리스크 해소: Q3 FS25 "OSG·PowerArtist 매각은 중국 SAMR 승인 지연으로 완료가 늦어지고 있어 ANSYS 통합 속도에 일부 제약" → Q4에 매각 완료, Q2에는 관련 언급 자체가 없음.

종합 인사이트

최신 분기의 핵심은 지난 3개 분기 내내 실적의 발목을 잡던 IP 사업이 실제 숫자(+12% QoQ, 마진 24.4%)로 바닥 통과를 증명했고, 그 위에서 회사가 FY26 가이던스를 매출·마진·EPS·FCF 전 항목에서 처음으로 상향했다는 점이다. 톤도 "전환기·부진한 한 해, 계절적 반등을 기대하지 말라"는 방어적 언어에서 "남은 분기에도 순차 성장을 지속할 것으로 확신"이라는 단정형으로 명확히 바뀌었으며, 이는 AI 인프라발 수요(HAV, 하이퍼스케일러 COT, 3DIC)가 구조적 순풍으로 자리잡았다는 판단을 반영한다. 확신 수준은 높게 볼 수 있는데, 인텔 파이프라인·Multiphysics Fusion 수익화·에이전트 소비 과금 등 상방 요인들이 가이던스에 미반영 상태로 남아 있어 추가 상향 여지가 있기 때문이다. 다만 백로그가 2개 분기 연속 감소($114억 → $110억)해 선행지표와 가이던스 상향이 엇갈리는 점, 비AI 시장(산업·자동차·아날로그) 부진이 4개 분기째 지속되는 점, 그리고 신규 수익모델(로열티·구독+소비)이 아직 '체결 예정·초기 탐색' 단계라 실제 수익화는 FY27 이후라는 점이 리스크다. Elliott의 이사회 진입은 마진·수익화 압력을 높이는 촉매인 동시에, 9월 Investor Day에서 제시될 목표가 공격적으로 설정될 경우 실행 부담이 커질 수 있는 양날의 변수다.
