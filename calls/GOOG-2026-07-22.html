QUARTER-OVER-QUARTER CHANGE ANALYSIS

GOOG — 최신 분기 변화 분석

비교 분기: 2025-10-29 · 2026-02-04 · 2026-04-29 · 2026-07-22 · 최신 분기 기준 수치·톤·확신 표현의 변화 (원문 인용 포함)

매출/이익 실적

  • 총매출 성장 가속 지속, 4분기 연속 가속: Q3'25 +16% → Q4'25 +18% → Q1'26 +22% → Q2'26 $1,198억, +24% — 12분기 연속 두 자릿수 성장
  • 클라우드 성장률 재차 급가속: Q1'26 +63%($200억) → Q2'26 +82%($248억). 4개 분기 궤적은 +34% → +48% → +63% → +82%로 매 분기 가속. "TPU 판매 제외해도 유의미한 가속"이라는 단서가 새로 붙음
  • 클라우드 마진 추가 확대: Q1'26 32.9% → Q2'26 35.6% (1년 전 20.7% 대비). 영업이익 $66억 → $88억(YoY 3배 이상)
  • YouTube 광고 재가속: Q1'26 +11%($99억) → Q2'26 +13%($111억) — 월드컵 효과로 Q4'25의 +9% 저점에서 2분기 연속 회복, DR뿐 아니라 "브랜드 주도"가 다시 언급
  • FCF 사상 첫 분기 마이너스 전환: Q1'26 +$101억 → Q2'26 -$59억(TTM $644억 → $533억). TPU 재고 선제 구축 + CapEx $449억(Q1 $357억 대비 +26% QoQ)이 원인
  • 전사 영업마진은 QoQ 하락: Q1'26 36.1% → Q2'26 34.0% — 가속 투자 국면에서 마진 피크아웃 가능성의 첫 신호

가이던스

  • FY26 CapEx 2개 분기 연속 상향: Q4'25 최초 제시 $1,750억~$1,850억 → Q1'26 $1,800억~$1,900억 → Q2'26 $1,950억~$2,050억 (최초 가이던스 대비 중간값 +11%). 2027년 "추가 대폭 증가" 예고는 유지
  • Q3 역풍 요인 신규 제시: Q2 환율 +1%p 순풍 → Q3 소폭 역풍, 그리고 "전년 Q3 Search 가속의 역기저 시작" — 이전 분기들에는 없던 광고 성장 감속 경고
  • 클라우드 마진 단기 압박 예고 신규: "Q3 서드파티 용량 사용으로 단기 마진 압박 + Wiz 통합 비용 역풍" — Q1의 Wiz 역풍 언급에 서드파티 브리징 비용이 추가

고객사·수주

  • 백로그 증가 모멘텀 둔화: $155B → $240B(+55% QoQ) → $462B(약 2배 QoQ) → $514B(+$500억, 약 +11% QoQ). 절대 규모는 사상 최대지만 QoQ 증가율은 급격히 축소 — 초대형 딜 사이클의 정상화 가능성
  • 엔터프라이즈 침투 지표가 '규모'에서 '포화'로: Q4'25 "Gemini Enterprise 800만 유료 시트, 2,800개 기업" → Q2'26 "포춘 100대 기업의 약 90%" 사용. 신규 고객 획득 속도 2배, 기존 고객 약정 초과 사용 +50%, 마켓플레이스 거래 7배 등 기존고객 확장(expansion) 지표가 전면에
  • TPU 외부 판매가 발표에서 실적으로: Q1'26 "일부 선별 고객에 직접 판매 개시" → Q2'26 "매출 인식을 Q2 처음 시작", Blackstone 프로젝트 등 구체 외부 배치 사례 등장. 대부분 매출은 2027년 인식 유지
  • API 토큰 처리량 지속 급증: 분당 100억(Q4'25) → 160억(Q1'26) → 220억(Q2'26), 월간 개발자 900만 명+

수요·리드타임

  • 공급 부족 서술이 '전망'에서 '3년 누적에도 해소 불가'로 강화: Q3'25 "수요-공급 타이트한 상황이 Q4와 2026년까지 지속될 전망" → Q2'26 "3년간 용량을 크게 늘렸지만 수요가 여전히 공급을 초과"
  • 서드파티 용량 브리징 신규 도입: 자체 증설만으로 수요를 못 받아 Q3부터 외부 데이터센터 용량을 임차 — "수개월간 비용은 높지만 다년 계약 전체로는 ROI가 매우 긍정적". 이전 분기까지는 자체 구축 효율성만 강조했던 것과 대비되는 질적 변화

Capex·재무구조

  • CapEx 분기 집행액 최대 경신: Q3'25 $240억 → Q4'25 $279억 → Q1'26 $357억 → Q2'26 $449억 (1년 새 약 1.9배)
  • 부채 급증 + 증자 — 자본구조 전환 신규 공개: 장기부채 "1년 새 $160억 → 약 $1,000억", 자금조달 우선순위를 "영업현금흐름 → 부채 → 주식"으로 명시. "SBC 세금 대응용 ATM 외 추가 증자 계획 없음"이라고 선을 그었으나, 순현금 기업이던 알파벳이 레버리지 성장으로 이동한 것은 이번 분기의 가장 큰 재무적 변화

신제품·기술

  • 경쟁 열세의 첫 공개 인정 — 톤 변화의 핵심: 이전까지는 자신감 일변도 — Q4'25 "지난 2년의 집요한 혁신 속도를 2026년에도 유지할 자신이 있음" → Q2'26 "에이전틱 코딩 열세는 인정하며 빠른 반복 개선 약속", "코딩·에이전틱 코딩 열세 인정, 3.6 Flash는 6주 만에 벤치마크 +10포인트 개선". 다만 전체 프런티어에 대해서는 "매우 자신" 유지
  • 출시 케이던스 전략 변화: Q3'25 "'눈에 띄게 개선된' 모델 출시에 시간이 더 걸릴 수 있다"(대형 점프 중심) → Q2'26 "Gemini 4를 베이스라인으로 삼아 이후 월 단위에 가까운 출시 케이던스로 반복 개선" — 경쟁 압박에 대응한 속도전 전환
  • Gemini 4 사전학습 진행 중(역대 최대 규모) — Q3'25의 "연내 Gemini 3 출시 예고"에 이은 차세대 사이클 가시화
  • 해자 논리의 이동: Q3'25 "자체 모델과 자체 기술로 풀스택을 구축한 유일한 하이퍼스케일러" (모델+인프라 우위) → Q2'26 "모델은 솔루션의 '재료'일 뿐 — 풀스택 통합 솔루션과 보안·거버넌스가 차별화" — 모델 성능 평준화 시나리오를 전제한 방어 논리로 재구성

마진·비용

  • 단기 비용 역풍의 구체화: 이전에는 "감가상각 역풍"(Q1'26) 일반론 → Q2'26은 서드파티 브리징 비용, Wiz 통합 비용, TPU 재고 선제 구축(현금흐름 부담)까지 세 가지 구체적 압박 요인을 동시 명시
  • Services 마진 하락: Q1'26 45.3% → Q2'26 41.8%

리스크 언급

  • 역기저 경고 신규: "전년 Q3 Search 가속의 역기저 시작" — 검색 성장률 감속을 회사가 선제적으로 예고
  • ROIC 방어 톤은 오히려 강화: Q1'26 "아직 극초기" → Q2'26 "아직 극초기(early innings) — 1년 전보다 더 낙관적", "장기 계약·갱신 수요 등 지표가 1년 전보다 건전" — CapEx 급증·FCF 마이너스에 대한 시장 우려를 의식한 적극적 반박 스탠스

종합 인사이트

최신 분기(Q2 FY2026)는 수요 사이클의 정점 구간에서 성장의 질이 바뀌는 분기다. 매출(+24%)과 클라우드(+82%)는 4분기 연속 가속으로 수요 자체는 의심의 여지가 없으나, FCF 첫 마이너스 전환, 부채 $160억→$1,000억, 서드파티 용량 임차, 2개 분기 연속 CapEx 상향은 회사가 자체 공급 능력의 한계를 넘어서는 수요를 레버리지와 외부 자원으로 쫓고 있음을 보여준다. 동시에 백로그 QoQ 증가율 둔화(약 2배 → +11%)와 Q3 검색 역기저 예고는 성장률 피크아웃의 초기 신호로 읽을 수 있다. 특히 주목할 것은 처음으로 "에이전틱 코딩 열세"를 공개 인정하고 출시 전략을 월 단위 케이던스로 바꾼 점 — 기술 리더십에 대한 서술이 공세에서 수세적 방어("모델은 재료일 뿐")로 이동했다. 종합하면 업황은 여전히 강한 상방이나(확신 수준: 높음), 투자 회수의 증거는 2027년 TPU 매출 인식과 클라우드 마진 유지 여부에 달려 있으며, 모델 경쟁 열세가 장기화되거나 백로그 순증이 추가 둔화될 경우 레버리지 확대가 리스크로 전환될 수 있다(확신 수준: 중간).
