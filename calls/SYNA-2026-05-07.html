QUARTER-OVER-QUARTER CHANGE ANALYSIS

SYNA — 최신 분기 변화 분석

비교 분기: 2025-08-08 · 2025-11-07 · 2026-02-05 · 2026-05-07 · 최신 분기 기준 수치·톤·확신 표현의 변화 (원문 인용 포함)

종합 인사이트

  • 성장 모멘텀 둔화: 전사 매출·Core IoT·EPS 성장률이 일제히 꺾인 분기임 (매출 +13%→+10% YoY, Core IoT +53%→+31% YoY, EPS +32%→+21% YoY)
  • 외형 자신감은 되레 강화: 둔화에도 FY26 Core IoT 가이던스를 장기 "25~30%"에서 "+40% 이상·$385M 이상"으로 대폭 상향함
  • 성장축 전환: Physical AI/로보틱스가 휴머노이드 파이프라인 35개+ 고객사로 급부상하며 새 성장 내러티브로 전면화됨
  • 확신 수준 양면성: 세미커스텀·Astra는 "홈런" 표현까지 쓰며 확신 강화, 반면 로보틱스 매출은 "그린필드라 보수적으로만 반영"으로 신중 유지
  • 리스크 톤 악화: 메모리 수급 영향이 Q2 "제한적"에서 Q3 "완전히 피하긴 어렵다"로 바뀌고, 중국 OEM 모바일 부진이 실적으로 현실화됨
  • 수익성: GPM 53.6% 방어했으나 매출 역성장에 OPM 19.2%→18.1%로 하락함

매출/이익 실적

  • 전사 매출 성장 둔화: $302.5M(+13% YoY) → $294.2M(+10% YoY), QoQ로도 역성장
  • Core IoT 성장률 반감: +53% YoY → +31% YoY (주도 동력은 "무선 커넥티비티"로 동일)
  • EPS 성장률 둔화: $1.21(+32% YoY) → $1.09(+21% YoY)
  • 영업이익률 하락: OPM 19.2%("+160bp QoQ, +190bp YoY") → 18.1%("YoY +약 260bp") — QoQ 레버리지 소멸
  • Mobile Touch 플러스→마이너스 전환: +3% YoY → -16% YoY (비중 16%→13%), 중국 OEM 메모리 수급 부진 직격
  • E&A 가속·비중 확대: "소폭 증가" → +9% YoY (비중 53%→57%), 부문별 성장 기여도 역전

가이던스

  • 분기 매출 가이던스 상향: FQ3 $290M ±$10M → FQ4 $305M ±$10M (중간값 +$15M)
  • EPS 가이던스 대폭 상향: FQ3 $1.00 ±$0.15 → FQ4 $1.20 ±$0.15
  • FY26 Core IoT 가이던스 상향: 장기 유지돼온 "25~30%" → "$385M 이상·YoY +40% 이상" (단 장기 목표는 "연 25% 이상"으로 명시 유지)

고객사·수주

  • 휴머노이드 확산: Q2 "선도 고객사 1곳에 샘플링(첫 디자인윈)" → Q3 "OEM 3곳에 추가 샘플, 파이프라인 35개 이상 고객사(선도 생성형 AI OEM 포함)"
  • 로보틱스 지역 분포 공개: (이전 미언급) → "진척 빠른 고객은 북미 집중, 일부 중국, 유럽은 초기 단계"
  • 신규 엔드마켓 디자인윈: (이전 CE/산업 중심) → 가정용 진단영상 의료기기, 북미 플릿 관리 OEM Astra 디자인윈 추가
  • 모바일 폴더블 고객 이동: Q2 "중국 선도 OEM 폴더블 디자인윈 추가" → Q3 "한국 OEM 플래그십 대부분 공급하며 점유율 확대" (중국은 부진으로 언급 전환)
  • Astra 양산 본격화: Q2 "Astra MPU 이번 분기 말~다음 분기 초 양산" → Q3 "현재 양산 중인 Astra 제품은 3종"

수요·리드타임

  • 모바일 수요 환경 반전: Q2 "모바일은 전량 프리미엄이라 물량 압박이 없습니다" → Q3 "메모리 부족을 겪는 중국 OEM 출하가 부진, 메모리 확보한 한국 OEM은 수혜"
  • PC 메모리 역풍 인정: Q2 "메모리 가격·공급 이슈 영향은 프리미엄 위주라 제한적" → Q3 "CY26 하반기 역풍 가능성은 있고, 회사도 그 영향을 완전히 피하긴 어렵다(엔터프라이즈·프리미엄 완충)"
  • DSO 급등: 39일 → 50일 (매출채권 회수일수 11일 증가)

마진·비용

  • GPM 방어: 53.6% → 53.6% (가이던스 중간값 소폭 상회 동일), GPM 기준선을 "53.5% 안팎"으로 재확인
  • OpEx 보합: $104.2M → $104.6M (큰 변화 없음)

신제품·기술

  • 웨어러블 세미커스텀 신규 공개: (Q2 미언급) → Astra SR 시리즈 지난달 테이프아웃, 가을 샘플링, "배터리 최대 2배, BOM 약 50% 절감", 대형 OEM향 CY27 상반기 양산
  • Google 협업 진전: Q2 "Coral NPU 실리콘 통합, Torq AI 도입" → Q3 "Astra SL2610 기반 차세대 Coral 보드 출시, 업계 최초 Google Coral NPU+Torq NPU 통합"
  • Connected MCU 상용 단계 진입: Q2 "Wi-Fi 7 통합 단일칩 초기 샘플링" → Q3 "Embedded World Best in Show 수상, 여러 고객사에 샘플링 중"
  • UWB IP 활용 입장 표명: (이전 미언급) → "Broadcom 인수 UWB는 현재 적극 투자하지 않지만 실내 위치 측위 용도는 계속 검토"

리스크 언급

  • 메모리 리스크 격상: 상기 수요 항목과 연동 — Q2 "영향 제한적" → Q3 "완전히 피하긴 어렵다"로 하방 리스크를 명시적으로 인정
  • 로보틱스 매출 신중론 신설: 성장축으로 전면화하면서도 "로보틱스는 아직 그린필드 시장이라 CY27 계획에는 보수적으로만 반영"으로 기대치 관리
  • 로봇 탑재금액 현실 수준 공개: 이전 "로봇 1대당 탑재 금액이 크게 높다"는 기대 → Q3 "현재 출하는 촉각 센싱·버스 인터페이스 대부분이고 플랫폼당 수십 달러 수준, Astra·무선은 초기 단계"로 현재 기여 규모 하향 톤
