QUARTER-OVER-QUARTER CHANGE ANALYSIS

SYNA — 최신 분기 변화 분석

비교 분기: 2025-08-08 · 2025-11-07 · 2026-02-05 · 2026-05-07 · 최신 분기 기준 수치·톤·확신 표현의 변화 (원문 인용 포함)

종합 인사이트

  • 업황 방향: Core IoT 고성장은 지속되나 성장률이 +74%→+53%→+31% YoY로 뚜렷이 둔화, 전사 YoY도 +13%→+10%로 감속함
  • 회사 상황: 성장 둔화를 FY26 Core IoT 연간 가이던스 상향과 '피지컬 AI/로보틱스' 신성장축으로 상쇄하며 내러티브를 전환 중임
  • 확신 수준: 메모리 리스크에 대해 이전 "물량 압박이 없습니다"에서 "완전히 피하긴 어렵다"로 한발 물러선 반면, Core IoT 연간 숫자는 상향하는 혼재된 톤
  • 리스크: 중국 OEM 메모리 수급난으로 Mobile Touch가 +3%→-16%로 역성장 전환, CY26 하반기 PC 메모리 역풍 가능성이 신규 리스크로 부상
  • 재무 신호: DSO 39→50일 급등·재고일수 101→106일로 운전자본 부담 확대, 다만 자사주 매입은 누적 $43.6M→$93M로 가속

매출/이익 실적

  • Core IoT 성장 둔화 가속: +53% YoY → +31% YoY (3분기 연속 감속: +74%→+53%→+31%)
  • 전사 매출 감속: $302.5M(+13% YoY) → $294.2M(+10% YoY)
  • EPS 증가율 둔화: $1.21(+32% YoY) → $1.09(+21% YoY)
  • Mobile Touch 역성장 전환: +3% YoY → -16% YoY (중국 OEM 메모리 수급 문제)
  • 영업이익률 QoQ 하락: 19.2% → 18.1% (YoY로는 +190bp → +약 260bp)
  • E&A 비중 확대: 매출 비중 53% → 57%, YoY 소폭 증가 → +9%
  • 연속 두 자릿수 성장: "5개 분기 연속" → "6분기 연속"

가이던스

  • 분기 매출 가이던스 상향: FQ3 $290M ±$10M → FQ4 $305M ±$10M, +5%
  • 분기 EPS 가이던스 상향: $1.00 ±$0.15 → $1.20 ±$0.15
  • FY26 Core IoT 연간 가이던스 대폭 상향: 이전 "FY26 Core IoT 성장률 가이던스 25~30%는 유지했다" → 최신 "FY26 Core IoT는 가이던스 중간값 기준 $385M 이상으로, YoY +40% 이상이다" (기존 25% 이상은 '장기 목표'로 재배치)

고객사·수주

  • 휴머노이드 파이프라인 급확대: 이전 "선도 고객사에 터치 컨트롤러와 브리지 칩을 샘플링" → 최신 "OEM 3곳에 추가로 샘플을 공급했다. 파이프라인은 35개 이상 고객사로 늘었고"
  • 신규 엔드마켓 디자인윈 추가: 가정용 진단영상 의료기기, 북미 플릿 관리 OEM(산업용)에서 Astra 디자인윈 확보 (신규)
  • 모바일 폴더블 고객 구도 변화: 이전 "중국 선도 OEM의 폴더블 디자인윈을 추가로 확보" → 최신 "한국 OEM 플래그십 대부분에 공급하며 점유율을 늘리고" (중국은 메모리 문제로 부진)
  • Google 협업 진전: Astra SL2610 기반 차세대 Coral 보드 출시, 업계 최초로 Google Coral NPU + 자사 Torq NPU 통합

수요·리드타임

  • 메모리 영향 인식 전환: 이전 "모바일은 전량 프리미엄·하이엔드 제품이라 현재 물량 압박이 없습니다" → 최신 "CY26 하반기 역풍 가능성은 있고, 회사도 그 영향을 완전히 피하긴 어렵다"
  • 지역별 수요 분화 신규: 메모리 부족으로 중국 OEM 출하 부진, 반면 메모리 확보한 한국 OEM에서 점유율 상승 수혜 (이전 분기엔 없던 분화 언급)

마진·비용

  • GM 톤이 '공세'에서 '방어'로: 이전 "53% 중반대 범위를 유지하면서 상단을 노리겠다는 입장입니다" → 최신 "원가 상승을 흡수하며 53.5% 안팎을 유지하고 있다" (GM 수치 자체는 53.6%로 동일)

신제품·기술

  • 웨어러블 세미커스텀 MCU 신규 공개: Astra SR 시리즈 지난달 테이프아웃, 가을 샘플링 — 배터리 수명 최대 2배·BOM 약 50% 절감, 대형 OEM향 CY27 상반기 양산 목표 (신규)
  • Connected MCU 외부 인증: Wi-Fi 7·BT 6.0 + Edge AI 단일칩이 Embedded World에서 Best in Show 수상, 현재 여러 고객사 샘플링 (이전 분기엔 '샘플링 시작' 단계)
  • 세미커스텀 진행 단계 전진: 이전 "대형 고객용 세미커스텀 MCU 4월경 테이프아웃" → 최신 "가을 샘플링 예정인 Google Coral NPU 탑재 세미커스텀 MCU"
  • CY27 램프 제품 구체화: 양산 Astra 3종 + Connected MCU + Coral NPU 세미커스텀 등 "3~4종이 CY27에 램프"

리스크 언급

  • 메모리 가격 역풍 신규 등장: CY26 하반기 PC 수요 역풍 가능성을 처음 언급, "완전히 피하긴 어렵다"고 인정
  • Mobile Touch 리스크 현실화: 중국 OEM 메모리 수급난이 실적에 -16% YoY로 반영
  • 운전자본 부담 확대: DSO 39일 → 50일 급등, 재고일수 101일 → 106일
  • 로보틱스 불확실성 명시: 신성장축으로 부각하면서도 "아직 그린필드 시장이라 CY27 계획에는 보수적으로만 반영했다"
