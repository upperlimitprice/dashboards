QUARTER-OVER-QUARTER CHANGE ANALYSIS

3008.TW · LARGAN 大立光 — 최신 분기 변화 분석

비교 분기: 2025-01-09 · 2025-04-10 · 2025-07-10 · 2025-10-09 · 2026-01-08 · 2026-04-16 · 2026-07-09 · 2026-10-08 · 최신 분기 기준 수치·톤·확신 표현의 변화 (원문 인용 포함)

매출/이익 실적

  • 변화 요지: 4Q24 매출 182.1억·GPM 59.15%·EPS 65.01(사상 최대) → 1Q25 145.8억·54.6%·48.28 → 2Q25 116.7억·53.63%·7.73(환손실 42.2억) → 3Q25 176.8억·47.2%·53.05 → 4Q25 172.2억·47.75%·50.4 → 1Q26 155.4억·49.41%·46.63 → 2Q26 136.6억·49.41%·35.72 → 3Q26 156.5억·42.21%·39.62 (NT$, 억). GPM은 8개 분기 동안 약 17%p 하락하며 3Q26에 2013년 이후 최저.
  • OPM 궤적: 4Q24 약 45.6% → 1Q25 약 41.8% → 2Q25 41.8% → 3Q25 약 35.4% → 4Q25 약 36.8% → 1Q26 37.4% → 2Q26 37.7% → 3Q26 30.25%. 1Q26~2Q26에 바닥을 다지는 듯했으나 3Q26에 다시 급락.
  • 성수기 매출의 역성장 전환: 3Q25 매출 YoY -7% → 3Q26 YoY -11.5%(7~9월 월매출 3개월 연속 YoY 감소). 2Q26은 YoY +17%였으나 저기저 효과였고, 성수기에 꺾임.
  • 4Q24 GPM 59%는 일회성: 회사가 직접 고객 출하 보너스(리베이트) 정산이라고 설명 — “若完成目標，客戶將額外提供出貨獎金”(목표 달성 시 고객이 출하 보너스 추가 지급). 이후 분기 GPM 비교의 기저가 높아짐.

출하 전망(拉貨·가동률)

  • 변화 요지: 4Q24 “只看到 1~2 月”(1~2월만 보인다)·“沒有滿載”(풀가동 아님) → 1Q25 4월<3월, 5월<4월(월별 감소) → 2Q25 7월>6월, 8월>7월·가동률 만재 → 3Q25 “10月與9月出貨差不多，11月會稍微差一點”(10월≈9월, 11월 약간 약화) → 4Q25 1월<12월, 2월 추가 하락·“比較沒有那麼緊”(그렇게 빡빡하진 않다) → 1Q26 “4月跟5月看起來會比三月差一點，六月還看不到” → 2Q26 “7月出貨優於6月，8月再優於7月”·“產能利用率應該是滿的”(가동률 만재) → 3Q26 “10月跟9月差不多，11月就會開始下滑”(11월부터 하락).
  • 4분기 전망 문구의 약화: 3Q25 “11月會稍微差一點”(약간 약화) → 3Q26 “11月就會開始下滑”(하락 시작). 같은 시기 문구가 '약간'에서 '하락'으로 강해짐.
  • 가동률 만재의 의미 변화: 2Q25 만재는 물량 덕분 → 3Q25 “目前產能是滿的，但不是因為客戶的量較多”(가동률은 풀이지만 고객 물량이 많아서가 아니다, 공정 복잡화 때문) → 1Q26 “但還是蠻緊的”(그래도 꽤 빡빡) → 3Q26 4Q 가동률은 여전히 만재지만 고객이 9월부터 물량을 줄임. 가동률 만재가 수요 강세를 뜻하던 시기는 끝남.

가이던스성 코멘트

  • 가시성 범위: 4Q24 2개월 → 1Q26 “六月還看不到”(6월은 아직 안 보임) → 2Q26 3Q 전체 매출은 “看不出來”(모르겠다) → 3Q26 내년은 보이지 않음(요지). 가시성은 늘 1~2개월로 짧았는데, 3Q26에는 다음 해 전체에 대한 불확실성까지 언급.
  • GPM 가이던스 방식: 1Q25 2Q GPM은 고객이 어떤 모델을 가져가느냐에 달림 → 1Q26 “客戶拉的是什麼樣的機種”(고객이 어떤 기종을 가져가느냐) → 2Q26 “良率是表現好壞的最關鍵因子”(수율이 실적의 최핵심 변수). GPM 변수가 제품 믹스에서 수율로 바뀜. 3Q26에 실제로 수율 부진이 GPM 급락으로 이어짐.

고객사·신규 스펙

  • 변화 요지: 4Q24 슬림폰 렌즈 “本來就有在做，但是量不多”(원래 하고 있지만 물량은 적다) → 1Q25 “較高難度的新鏡頭大立光可以量產，但別人我不知道”(고난도 신규 렌즈는 우리는 양산 가능, 남은 모르겠다) → 3Q25 내년 업그레이드는 가변조리개, 잠망경은 대체로 기존 설계 유지 → 4Q25 가변조리개 사양 미확정(2Q lock down, 3Q 출하)·올해 잠망경 업그레이드 없음 → 2Q26 2027년 잠망경 inner zoom → 3Q26 2027년은 메인 렌즈(대형 CIS) 업그레이드, 잠망경 업그레이드는 2028년으로 연기.
  • 가변조리개의 기대에서 부담으로: 2Q25 대형 프로젝트, ASP 상승·GP% 하락 → 3Q25 “測越多光站，偵測出的瑕疵點（defects）越多”(검사 공정이 많을수록 결함도 많이 잡힌다) → 1Q26 잠망경보다 마진이 나을지는 수율을 봐야 앎 → 3Q26 iPhone 18 Pro 기계식 가변조리개 수율 부진이 GPM 급락의 주원인. 현재 수율은 “目前看起來還OK”(지금은 괜찮아 보인다).
  • 비(非)스마트폰 응용 축소: 4Q24 휴머노이드 로봇 “客戶不只一家”(고객이 한 곳이 아니다)·“目前硬體OK” → 3Q25 로봇 렌즈 출하 2026년으로 지연·AI 안경은 고객 협업 → 1Q26 로봇·차량은 CPO/FAU보다 R&D 우선순위 뒤. 신규 성장 축의 중심이 CPO로 옮겨감.

수요·가시성

  • 변화 요지: 1Q25 관세 “目前沒有受到直接影響”(현재 직접 영향 없음) → 2Q25 희토류 통제 후 “是OK了”(이제 괜찮다) → 4Q25 메모리 비용 탓에 중소 고객이 렌즈 업그레이드 둔화(대형 고객은 유지) → 1Q26 “稍微upside”(수요가 약간 상향) → 2Q26 “吃掉我們的未來”(AI가 카메라 업그레이드 수요를 먹어치울 수 있다) → 3Q26 고객이 9월에 수요 전망 하향, 2026년 판매가 기대 미달.
  • 수요 리스크의 질적 변화: 관세·희토류 같은 외부 충격(2025년) → 메모리 비용발 중소 브랜드 스펙 둔화(4Q25~1Q26) → 주 고객 신제품 판매 부진(3Q26). 문제가 주변에서 핵심 고객으로 옮겨옴.

가격·경쟁

  • 변화 요지: 4Q24 고객이 경쟁사보다 많이 출하한 대가로 리베이트(요지)·유리렌즈는 중국 경쟁사가 강해 자체 생산 안 함(요지) → 2Q25 “去年有些大機種是獨家供應，今年對手會陸續跟進”(작년 독점 공급 대형 기종에 올해 경쟁사가 따라온다) → 3Q25 “雖然今年有競爭者，但講好的份額還是一樣”(경쟁자가 있어도 합의된 점유율은 같다) → 2Q26 가변조리개에도 “第二供應商”(제2 공급사) 존재(기자는 舜宇로 지목) → 3Q26 중국 경쟁사 직접 언급 없음.
  • 독점 해소 인정의 누적: 2025년 대형 기종 독점 해소 → 2026년 신규 스펙(가변조리개)도 첫해부터 듀얼 소싱. 새 스펙에서 독점 기간을 누리던 과거와 달리 신규 사양의 초기 프리미엄이 줄었다(생각).
  • 가격: 1Q25 가격 변동 없음 → 2Q25 “第二季因新機高規格料號鏡頭出貨，取得比較好的交貨價格”(2Q 고사양 신규 렌즈로 더 나은 가격) → 이후 콜에서 가격 인상 언급 없음. 1Q26에는 저마진 프로젝트는 받지 않겠다는 방어 문구(요지).

Capex·신공장

  • 변화 요지: 4Q24 FY24 capex 107억(최초 100억 돌파)·신공장 2025년 9월 완공 → 1Q25 29억 → 2Q25 35.6억(신공장 설비) → 3Q25 약 34억·“最新的第4廠一個樓層已經規劃，未來還有空間”(4공장 한 층 계획, 공간 여유) → 1Q26 23.9억·타이중 공장 클린룸 15.44억 발주 → 2Q26 약 27.8억·인력·토지 부족 → 3Q26 81.8억(대부분 토지)·타이중 부지 7곳 80억+.
  • 투자 목적의 전환: 2025년 스마트폰 렌즈 신공장(공간 여유) → 3Q26 FAU 전용 신공장 “這相當於我們現有的廠區第二大”(기존 공장 중 두 번째 규모). 공간이 남던 회사가 1년 만에 토지를 대규모로 매입하는 쪽으로 바뀜.

CPO 신사업

  • 변화 요지: 3Q25 언급 없음 → 4Q25 첫 등장, TSMC 협력 보도에 “無所不包、成功再說”(뭐든 다 한다, 성공하면 말하겠다) → 1Q26 최우선 프로젝트, “這個project本來就不是今年可以量產的”(올해 양산할 건이 아니다)·“還有很長的距離”(아직 갈 길이 멀다) → 2Q26 FA 7월 샘플·3Q 말 파일럿 라인, “不會那麼快，最快要明年中”(빨라야 내년 중반) → 3Q26 FA 9월 고객 1곳 인증 통과·2Q27 말 라인 구축·FAU 2H27 양산, “不論FA或FAU都很缺，客戶都希望你盡量建產線”(FA·FAU 모두 부족, 고객은 최대한 증설 원함).
  • 톤이 가장 크게 바뀐 영역: “成功再說”(성공하면 말하겠다, 4Q25) → “還有很長的距離”(갈 길이 멀다, 1Q26) → “最快要明年中”(일정 제시, 2Q26) → “都很缺”(공급 부족, 3Q26). 9개월 만에 말을 아끼던 태도가 일정·캐파까지 제시하는 쪽으로 바뀜. 사업 범위도 부품(FA)에서 모듈(FAU+Carrier)로 넓어짐.

마진·비용(수율·환율·그린전력)

  • 변화 요지: 4Q24 리베이트로 59% → 1Q25 1Q GPM은 4Q 수준 재현 불가 → 2Q25 “這個會影響蠻大的”(환율 영향이 꽤 크다), NT$ 10% 절상 시 GPM -4~5%p → 3Q25 “毛利率下滑主要受匯率與Bypass Revenue 增加導致”(GPM 하락은 환율과 bypass 매출 증가 탓), 잠망경 초기 수율 부진 → 4Q25 스크랩 비용·소량 다품종으로 금형 효율 저하 → 1Q26 스크랩 감소는 플러스, 수율·고정비·전기료는 마이너스 → 3Q26 가변조리개 수율 부진 + 그린전력 “綠電是結構性問題”(그린전력은 구조적 문제)·2028년 전까지 가격 전가 불가.
  • 마진 하락 원인의 성격 변화: 일회성·외부 요인(환율, 2025년) → 운영 요인(스크랩·수율, 4Q25~1Q26) → 구조적 비용(그린전력, 3Q26). 앞의 둘은 되돌릴 수 있지만 그린전력은 2027년 가격이 이미 정해져 1년 넘게 부담으로 남음(생각).

주주환원

  • 변화 요지: 1Q25 “會再考慮是否實施庫藏股”(자사주 매입 재검토, 요지) → 4Q25 자사주 2,670장 매입을 2/2에 조기 완료(평균 2,424.82), 저PER에 “不該是最差的”(광학주 중 꼴찌여선 안 된다) → 2025년 배당 합계 80 NT$(1H25 28·2H25 52) → 2Q26·3Q26 콜에서 주주환원 언급 확인 안 됨. 3Q26 현금 약 1,109억·차입 계획 없음.

리스크 언급

  • 변화 요지: 1Q25 관세(직접 영향 없음)·해외 이전 시 원가 상승 → 2Q25 희토류 통제로 일시 출하 공백 “有一段時間沒有貨可以出”(한동안 출하할 물건이 없었다)·환율·“真的滿難”(대만을 떠나기는 정말 어렵다) → 4Q25~1Q26 메모리 가격발 중소 고객 스펙 둔화 → 2Q26 AI의 카메라 대체 → 3Q26 주 고객 판매 부진·그린전력·가변조리개 수율. 리스크가 외부 거시 변수에서 회사 자체 수익 구조로 옮겨옴.

분기별 톤 점수

  • 4Q24 (2025-01-09): 톤 +1 (낙관) — 사상 최대 EPS 65.01·GPM 59%, 다만 “只看到 1~2 月”·“沒有滿載”로 단기 신중 유보
  • 1Q25 (2025-04-10): 톤 0 (중립) — 관세 “目前沒有受到直接影響”, 2Q는 월별 감소하는 비수기, “較高難度的新鏡頭大立光可以量產”로 기술 자신감 유지
  • 2Q25 (2025-07-10): 톤 0 (중립) — 7·8월 출하 증가·가동률 만재 vs 독점 기종 경쟁사 진입·환손실 “影響蠻大”
  • 3Q25 (2025-10-09): 톤 -1 (신중) — GPM 47.2%로 8분기 최저, “產能是滿的，但不是因為客戶的量較多”, 점유율은 유지
  • 4Q25 (2026-01-08): 톤 -1 (신중) — “比較沒有那麼緊”, 중소 고객 스펙 둔화, 자사주 매입으로 방어, CPO는 “成功再說”
  • 1Q26 (2026-04-16): 톤 0 (중립) — “還是蠻緊的”·“稍微upside”로 소폭 개선, CPO 최우선화하되 “還有很長的距離”(다음 날 주가 -7.6%)
  • 2Q26 (2026-07-09): 톤 +1 (낙관) — “7月出貨優於6月，8月再優於7月”·가동률 만재, CPO 파일럿 일정 구체화. 다만 “吃掉我們的未來” 경계
  • 3Q26 (2026-10-08): 톤 -1 (신중) — 본업은 GPM 42.2%·“11月就會開始下滑”·내년 미가시로 -2 수준이나, CPO “都很缺”·FA 인증 통과가 상쇄

종합 인사이트

  • 8개 분기 동안 본업 스마트폰 렌즈의 톤은 “只看到 1~2 月”(짧은 가시성 속 자신감) → “產能是滿的，但不是因為客戶的量較多”(가동률이 수요를 뜻하지 않음) → “11月就會開始下滑”(성수기 조기 꺾임)으로 꾸준히 낮아졌고, GPM은 59%(일회성 포함)에서 42%로 약 17%p 하락했다.
  • 마진 하락 원인은 환율(2025년) → 수율·스크랩(4Q25~1Q26) → 그린전력(3Q26)으로 바뀌었다. 2028년 전까지 전가가 어렵다고 회사가 직접 밝힌 만큼, 4Q26~2027년 GPM이 40%대 초중반을 회복하기는 쉽지 않다(생각).
  • 반대로 CPO는 “成功再說”에서 “都很缺”까지 9개월 만에 톤이 가장 빠르게 높아졌다. 3Q26 대규모 토지 매입(81.8억)과 두 번째 규모의 FAU 전용 공장은 경영진의 확신이 말이 아닌 자본 배분으로 확인된 신호다(생각).
  • 결국 대립광은 경쟁 심화·스펙 둔화로 마진이 구조적으로 낮아지는 렌즈 본업과, 2H27 양산 전까지 숫자가 없는 CPO가 교차하는 구간에 있다. 확신도는 본업은 낮고 신사업은 높다.
  • 리스크는 주 고객 판매 부진의 지속(2027 메인 렌즈 업그레이드, 잠망경은 2028년), 가변조리개·FAU 수율, 가변조리개 제2 공급사로 상징되는 신규 스펙 듀얼 소싱이다. 10~12월 월매출과 FAU 캐파 규모 공시가 다음 확인 지점이다(생각).
