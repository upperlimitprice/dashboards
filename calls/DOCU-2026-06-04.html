QUARTER-OVER-QUARTER CHANGE ANALYSIS

DOCU · docu — 최신 분기 변화 분석

비교 분기: 2025-09-04 · 2025-12-04 · 2026-03-17 · 2026-06-04 · 최신 분기 기준 수치·톤·확신 표현의 변화 (원문 인용 포함)

매출/이익 실적

  • 매출 성장률 재가속: Q3 +8% YoY($818M) / Q4 +8%($837M) → Q1 FY27 +9%($830M, 가이던스 상단 상회). 다만 FX 효과 약 +1.6%p 포함이며, 비트 폭은 예년보다 축소 (경영진: "예측 정밀도가 높아지면서 비트 폭이 줄어든 것일 뿐 견조한 실행의 분기였다")
  • 영업이익률 사상 최고 경신: Q2 29.8% → Q3 31.4% → Q4 29.5% → Q1 FY27 32.0% (YoY +2.5%p, 가이던스 중간값 대비 +2.75%p). Non-GAAP 영업이익 $266M(+18% YoY)로 매출 성장(+9%)을 크게 웃도는 레버리지 시현
  • EPS 가속: Non-GAAP 희석 EPS $0.92(Q2) → $1.01(Q3) → $1.01(Q4) → $1.09(Q1, +21% YoY) — 바이백에 의한 주식수 감소(-8% YoY, 1억 9,650만 주) 효과 결합
  • FCF 마진: 27%(Q2) → 32%(Q3) → 42%(Q4) → 35%(Q1) — 계절성 감안해도 전년 동기 30% 대비 +5%p
  • 해외 성장 뚜렷한 가속: +13%(Q2) → +14%(Q3) → +15%(Q4) → +17%(Q1), 매출 비중 29% → 31%. "EMEA가 신임 리더십 하에 뚜렷이 개선됐고 해외는 북미보다 도입이 초기라 기회가 더 큼" (FX 제외 시에도 두 자릿수)

가이던스

  • 핵심 지표 전환 완료: 빌링스 가이던스 폐지 → FY27부터 ARR 중심(연간 +8.25~8.75%, 중간값 +8.5%). Q1에서 이 ARR 가이드와 IAM 비중 18% 목표를 그대로 유지 — Q4에서 예고한 "ARR 가이던스는 연간 예약 전망 변화 시에만 수정 방침"대로 분기 조정 없음
  • 연간 영업이익률 가이드 상향: FY27 30.0~30.5%(Q4 시점) → 30.5~31.0%(Q1, 중간값 +0.5%p 상향) — 톱라인 유지 속 수익성만 올린 구조
  • 가이던스 성격 변화: FY26 중에는 분기마다 매출·빌링스 중간값을 상향(+$38M, +$15M/+$44M)했으나, FY27 들어서는 ARR 유지 + 마진 상향으로 상향의 축이 이익 쪽으로 이동

고객사·수주

  • IAM 고객 수 급증 지속: 1만 개(4월'25) → 2만 5,000개(Q3) → 4만 개(Q1 FY27); IAM의 ARR 비중 2.3%(FY25 말) → 10.8%(Q4) → 12.6%(Q1), 연말 목표 약 18%($600M+)
  • 대형 고객 성장률 처음으로 두 자릿수: $30만+ 고객 +7%(Q2, 1,137개) → +8%(Q3) → +7%(Q4, 1,205개) → +12%(Q1, 1,258개) — "3년 만에 처음으로 두 자릿수 성장"
  • 엔터프라이즈 침투 단계 변화: Q2 "올해 엔터프라이즈 기여에 크게 의존하지 않지만 장기적으로 더 큰 기회" → Q4 "엔터프라이즈는 아직 초기" → Q1 "IAM 예약(bookings)은 북미 엔터프라이즈 부문에서 가장 빠른 YoY 성장을 기록 — 대형 고객으로의 IAM 침투가 본격화되는 초기 신호"
  • DNR 개선 사이클 연장: 102%(Q2, "6개 분기 연속") → 102% 이상(Q1, "7개 분기 연속 개선"); 총유지율(GRR)도 "전사적으로 집중 중이며 성과가 나타나기 시작"

마진·비용

  • 클라우드 이전 역풍의 소멸: FY26 내내 "클라우드 이전으로 연간 약 1%p 역풍, 올해가 피크"(Q2)라며 매출총이익률 하락(-50~-70bp YoY)을 설명 → Q1 FY27은 매출총이익률 81.5%가 "예상 상회"로 언급되고 역풍 코멘트 자체가 사라짐
  • SBC·인력 효율화 진전: SBC 매출 대비 19% → 17%; 임직원 7,044명(Q4) → 6,991명(Q1, 순감) — Q4의 "절감된 GTM 효율을 R&D에 재투자" 기조가 실제 숫자로 확인

신제품·기술

  • AI 데이터 자산 규모 확대: 동의 기반 계약 문서 약 1억 건(Q2) → 1.5억 건(Q3) → 2억 건 이상(Q4~Q1); 정밀도·재현율 +15%p, LLM 직접 프롬프트 대비 처리비용 50배 최적화 주장 유지
  • 에이전틱 전략의 구체화: Q2 "수개월 내 IAM 내 AI 에이전트 출시 예정" → Q3 "첫 AI 계약 에이전트 베타 출시" → Q1 3축 전략 공식화(Iris 사전구축 에이전트 / Agent Studio 커스텀 / MCP 서버 서드파티 연결) + "MCP 베타에 수천 명이 등록하는 전례 없는 관심"
  • 파트너십 폭 확대: Q3 ChatGPT·Claude·Gemini 등 챗 플랫폼 중심 → Q1 Momentum에서 법무(Harvey, Legora, CoCounsel)·조달(Coupa)·HR(Workday, Greenhouse)·결제(Stripe)·협업(Slack)까지 버티컬 워크플로 전반으로 확장
  • 소비형 가격제 상용화: Q4 "40~50개 고객 시범 결과 반응이 좋아 다음 달 출시" → Q1 "크레딧 기반 'IAM Platform Plan'을 베타를 거쳐 4월 엔터프라이즈 대상 GA"
  • 개발 생산성: 신규 코드의 AI 지원 작성 비중 60%(전분기) → 약 75%
  • 경영진 보강: 신임 CPO Graham Sheldon(전 UiPath CPO, 전 MS Teams 총괄) 영입 — 제품 조직 강화 신호

리스크 언급

  • 매크로 코멘트의 소멸: Q2 "거시경제 약화 신호는 관찰되지 않음", Q3 "최근 4~5개 분기 동안 특이 신호 없이 소비·이용 트렌드가 일관" → Q4·Q1에서는 매크로 언급 자체가 사실상 사라짐 — 리스크 화두가 거시에서 실행·경쟁으로 이동
  • 애널리스트 압박 포인트 변화: Q2에는 경쟁(범용 LLM 벤더)·SEO 리스크 질문 → Q1에는 "취임 3년 반이 지났는데 아직 두 자릿수 성장이 아니다"라는 성장 속도 자체에 대한 직접적 도전과 "이번 분기 비트 폭이 예년보다 작았는데"라는 실적 질(質) 질문이 등장. 경영진은 "실적에 전혀 우려 없음", "진척에 실망하지 않으며 오히려 만족"으로 방어

톤·확신 수준의 변화

  • 성장 전망: Q2 "한 분기를 카테고리 전환점으로 과잉 해석하지 말라"(CLM 강세에 대한 절제) → Q4 "두 자릿수 성장은 장기 열망 목표로 달성 가능하다고 보나 구체적 시점은 제시하지 않음" → Q1 "올해와 향후 수년간 성장 가속을 전망" — 다년(multi-year) 가속을 명시적으로 약속하는 수준으로 확신 상승
  • IAM 리텐션 평가: Q2 "IAM의 그로스 리텐션은 eSign보다 높게 나타난다(표본은 작음)" → Q4 "표본이 작아 '신중한 낙관' 단계" → Q1에서는 유보 문구 없이 DNR "7개 분기 연속 개선"과 GRR "성과가 나타나기 시작"으로 단정적 서술
  • AI 경쟁 구도 인식: Q2 "경쟁을 안이하게 보진 않지만 데이터·워크플로·고객 접점 측면의 고유한 위치가 강점"(방어적) → Q4~Q1 "모델 업체들은 오히려 DocuSign에 파트너십을 먼저 제안(인바운드)하는 상황", "상당수 파트너십은 상대측의 인바운드 요청으로 성사"(공세적) — 위협 서사에서 순풍 서사로 전환

종합 인사이트

4개 분기를 관통하는 그림은 "IAM 플랫폼 전환의 검증 단계 통과"다. IAM ARR 비중이 1년 만에 2.3%→12.6%로 오르고, 대형 고객 성장이 3년 만에 두 자릿수(+12%)로 복귀했으며, DNR 7분기 연속 개선까지 겹치면서 경영진의 언어가 "과잉 해석 말라"에서 "향후 수년간 성장 가속"으로 뚜렷이 강해졌다. 동시에 클라우드 이전 역풍 소멸·인력 순감·SBC 하락으로 마진 가이던스까지 상향해, 성장 재가속과 수익성 확대를 동시에 주장할 수 있는 드문 위치에 있다. 확신 수준은 "리텐션 개선 + IAM 확장"이라는 두 레버 모두 실측 데이터로 뒷받침되어 비교적 높다. 다만 리스크로는 ① 헤드라인 성장률이 여전히 8~9%에 머물고 FX(+1.6%p)가 착시를 만드는 점, ② 비트 폭 축소·빌링스 변동성에 대한 애널리스트 의구심, ③ IAM 비중 18% 목표가 "선형 진행" 가정이라 엔터프라이즈 대형 딜 지연 시 하방이 열리는 점을 병기해야 한다.
