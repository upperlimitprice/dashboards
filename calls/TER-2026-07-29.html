QUARTER-OVER-QUARTER CHANGE ANALYSIS

TER — 최신 분기 변화 분석

비교 분기: 2025-10-29 · 2026-02-03 · 2026-04-29 · 2026-07-29 · 최신 분기 기준 수치·톤·확신 표현의 변화 (원문 인용 포함)

매출/이익 실적

  • 매출 신기록 연속, 단 QoQ 성장률은 급감: Q1 FY26 12.82억 달러(QoQ +18%) → Q2 FY26 13억 달러 이상(QoQ +4%). 2개 분기 연속 사상 최대이나 순차 성장 모멘텀은 둔화.
  • EPS·마진은 Q1 피크 대비 소폭 하락: non-GAAP EPS $2.56 → $2.47, 매출총이익률 60.9% → 59.8%(-110bp), 영업이익률 37.5% → 33.7%. 회사 설명은 "Q1 일회성 효과 소멸 영향"으로 일관.
  • 컴퓨트 폭발적 성장이 수치로 명시: Q1은 "컴퓨트가 SoC 제품 매출의 약 75%"라는 비중만 제시 → Q2는 "컴퓨트 매출 전년비 약 +600%"로 성장률을 직접 공개 (SoC 내 비중은 75% → 70%로 소폭 하락 = 비컴퓨트 회복 시사).
  • IST 급증: Q1 $27M → Q2 $67M(QoQ +150% 이상, YoY +94%). "AI향 HDD 수요, 3대 공급사 전부에서 발생" — 고객 다변화가 실적으로 확인.
  • 메모리 분기 최대 경신 지속: $203M → $212M, 3개 분기 연속 $200M 이상.
  • Product Test 가속: $80M(YoY +8%) → $107M(YoY +26%, QoQ +33%).
  • 로보틱스 $100M 돌파: $91M → $100M(YoY +33%), 전자제조·반도체 세그먼트가 QoQ +50%로 최대 세그먼트 부상 — Q1의 "이커머스 물리 AI" 서사에서 데이터센터/반도체 연계 서사로 이동.

가이던스

  • 상반기 편중 완화 = 하반기 실질 상향: 연간 상반기 매출 비중 Q4'25 콜 "약 60%" → Q1'26 콜 "55~60%" → Q2'26 콜 "50~52%로 업데이트(하반기 전망 강화·범위 축소)". 상반기 매출이 이미 26억 달러이므로 산술적으로 연간 전망이 계속 올라가는 구조.
  • 목표 모델 '유지'에서 '상향 예고'로: Q1'26 "연간 목표 모델(매출 60억 달러, Non-GAAP EPS 9.50~11달러) 유지" → Q2'26 "목표 수익 모델(target earnings model) 업데이트를 4분기 실적 발표에서 공유 예정" + "ATE TAM이 200억 달러에 도달하거나 상회할 수 있다는 시각"(기존 모델 기준 TAM은 120~140억 달러였음).
  • 2027년 전망이 처음 명시적으로 긍정 제시: Q1'26은 하반기조차 "하반기 가시성은 제한적", "불확실성으로 공식 제시하지 않음" → Q2'26 "2027년에도 ATE TAM 확대와 점유율 확대에 힘입어 건실한 성장 재개를 예상".
  • Q3 가이던스상 수익성은 피크 대비 하락: 매출총이익률 58~59%, 영업이익률 28~30% (Q1 실적 37.5% 대비 뚜렷한 레벨 다운, OpEx 비중 27~28% → 29~30%).

고객사·수주

  • 머천트 GPU: '수주'에서 '납품 완료 + 2번째 고객'으로 진전: Q1'26 "첫 다중 시스템 양산 테스트 수주 확보. 2분기 출하·설치·양산 가동 예정" → Q2'26 "머천트 GPU 고객 첫 주문을 2분기에 납품 완료했고, 두 번째 대형 하이퍼스케일러와 상관(correlation) 검증 완료 — 2027년 점유율 확대 확신 강화". 4개 분기 궤적이 뚜렷함: Q3'25 "진전은 있으나 수주 확정 전이며 3분기 실적과 4분기 가이던스에 미포함" → Q4'25 "생산 인증 진행 중" → Q1'26 수주 → Q2'26 납품 완료.
  • 점유율 서사의 시제 변화: Q1'26 "중기적으로 30~70% 범위 진입까지 수년 소요" → Q2'26 "이제 안정화 후 상승 전환 중이며, 점유율 효과는 2027년부터 소켓별로 점진적으로 나타날 것" — 추상적 '수년'에서 '2027년'이라는 구체 시점으로.
  • 메모리 수주잔고 지표 신규 공개: Q2'26에서 처음 "메모리 수주잔고 북투빌 2 이상" 언급 — 이전 분기들에는 없던 정량적 백로그 신호.

수요·리드타임

  • NAND: '역사적 저점'에서 '변곡점 확인'으로: Q3'25 "NAND는 역사적 저점 수준… 2025년보다 개선을 조심스럽게 기대" → Q2'26 "낸드는 기다리던 고객 수요 변곡점이 실제로 나타나 캐파 추가 요청이 들어오기 시작했다". 조심스러운 기대가 실현된 사례.
  • 메모리 TAM 전망의 구체화·상향: Q4'25 "2026년 메모리 TAM은 낮은 두 자릿수 성장 전망" → Q1'26 "1월 전망보다 강세" → Q2'26 "2026년 메모리 TAM은 2025년 대비 40% 이상 커질 전망". 낮은 두 자릿수 → +40% 이상으로 대폭 상향. DDR도 "CPU 수요 부활·엣지 AI향 LPDDR이 1월 예상보다 강하다"고 명시.
  • 자동차/산업: 불확실에서 고점 회복 전망으로: Q3'25 "모바일·자동차/산업·로보틱스는 회복을 예상하나 시기와 강도는 불확실" → Q2'26 "2027년에 이전 고점에 도달하거나 상회할 것으로 본다(잠정 판단)".
  • TAM 가시성에 대한 태도 반전: Q1'26 "2025년에도 4월 시점 TAM 전망이 크게 빗나갔던 만큼 확신이 없어 공개하지 않음… Advantest 수치가 터무니없지는 않으나 자체 전망을 공유할 만큼 확신하지 못함" → Q2'26 "Advantest가 제시한 TAM 수치는 대체로 타당하다". 불과 한 분기 만에 외부 TAM 추정을 사실상 승인.
  • 새로운 톱다운 프레임 도입: Q2'26에서 처음 WFE 대비 테스트 CapEx 비중 프레임 제시 — "테스트 장비의 반도체 CapEx 비중이 2023년 약 4% → 2025년 7% → 2026년(1~5월) 8%… 7~9% 범위에서 안정화될 것". 상향 근거를 구조적(어드밴스드 패키징) 논리로 격상.
  • 유일한 수요 역풍: 하반기에 "모바일 부진과 컴퓨트 주문 타이밍"이 성장을 상쇄한다고 명시 — 모바일 약세가 이번 분기 새로 부각된 부정 요인.

마진·비용

  • 마진 피크아웃, 단 '정상 변동' 프레임: 매출총이익률 Q1 60.9% → Q2 59.8% → Q3 가이드 58~59%. 회사는 "분기별 변동은 정상적(과거 5년 분기 간 약 400bp 스윙, 연간으로는 200bp 이내)… 연간으로는 약 59%로 목표 모델에 근접"이라고 방어. 다만 "메모리는 2027년에도 마진 부담 요인"이라는 새 경고 추가.
  • OpEx 기조 전환이 수치로 확인: Q1'26 OpEx 가이드 "매출의 27~28%" → Q3'26 가이드 "29~30%". Q1의 "G&A·판관비는 억제하고 R&D에 집중 투자" 방침이 "R&D·고객대응 조직 투자를 선제적으로 확대 중"으로 이어지며 영업이익률 가이드도 30~32% → 28~30%로 하향.

신제품·기술 / M&A

  • 포토닉스 역량 추가 인수: Q1'26 MultiLane JV 클로징 + TestInsight 인수(합산 약 1.65억 달러)에 이어 Q2'26 Quantifi Photonics 인수 추가 — "광·구리 인터커넥트 전 영역 대응" 포트폴리오 완성 서사.
  • CPO TAM 전망의 시점 구체화: Q1'26 "중기적으로 연 3억~7억 달러 TAM" → Q2'26 "2028년 3억~7억 달러" + "내년(2027년)은 약 2억 달러 수준의 하단 쪽으로 예상" — 막연한 '중기'에서 연도별 숫자로.
  • Omnyx 상업화 진전: Q1 "신제품 출시" → Q2 "신규 보드테스트 플랫폼(Omnyx) 2분기 출하 개시".

리스크 언급

  • 리스크의 성격이 '수요 불확실성'에서 '타이밍·믹스'로 이동: Q1'26 "대형 고객 주문의 lumpiness와 데이터센터 구축 생태계의 병목에 따른 검수 지연 리스크" → Q2'26의 하방 요인은 "모바일 부진과 컴퓨트 주문 타이밍", 그리고 "2027년엔 (테스트 CapEx) 비중이 6~7%대로 되돌아갈 수 있으나, TAM 자체는 확대될 것" — 수요 자체보다 비중 정상화·분기 배분 문제로 축소.
  • 중국 로컬라이제이션 리스크 신규 언급: Q2'26에서 자동차 파워 반도체 관련 "로컬 경쟁이 있지만 잘 협력 중인 고객도 있다"로 처음 거론 — 심각도는 낮게 처리.

종합 인사이트

최신 분기(Q2 FY2026)의 가장 큰 변화는 확신의 레벨업이다. 한 분기 전만 해도 "확신이 없어 공개하지 않음"이라던 TAM 전망을 이번엔 승인·구체화했고, 머천트 GPU는 수주→납품 완료→2번째 하이퍼스케일러 검증으로 실체화됐으며, 상반기 편중 우려(60%)는 50~52%로 해소돼 하반기가 사실상 상향됐다. 여기에 4분기 목표 모델 업데이트 예고와 "ATE TAM 200억 달러" 발언은 기존 60억 달러 매출 목표의 상향을 강하게 시사한다. 다만 마진·영업이익률은 Q1을 정점으로 내려오는 궤적이고(GM 60.9% → 가이드 58~59%, OPM 37.5% → 가이드 28~30%), OpEx 선행 투자 확대와 메모리 믹스 부담이 2027년까지 이어질 수 있다. 리스크는 수요의 방향이 아니라 타이밍이다 — 회사 스스로 테스트 CapEx 비중이 2027년 6~7%대로 되돌아갈 수 있다고 인정한 만큼, 2026년의 +100% 성장률을 연장 추정하는 것은 경계해야 하며, 모바일 부진과 컴퓨트 주문의 lumpiness가 분기 단위 변동성을 키울 수 있다.
