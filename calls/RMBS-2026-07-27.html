QUARTER-OVER-QUARTER CHANGE ANALYSIS

RMBS · rmbs — 최신 분기 변화 분석

비교 분기: 2025-10-27 · 2026-02-02 · 2026-04-27 · 2026-07-27 · 최신 분기 기준 수치·톤·확신 표현의 변화 (원문 인용 포함)

매출/이익 실적

  • 매출 사상 최대, 첫 $200M 돌파: 1Q26 $180.2M("가이던스에 부합") → 2Q26 $207.4M (YoY +20%, QoQ +15%), "사상 최대를 기록하며 처음으로 $200M을 넘어섰다". 직전 분기는 "부합"이었으나 이번엔 "매출과 non-GAAP EPS 모두 가이던스 상단을 넘었다"로 비트 강도가 한 단계 올라감.
  • 제품 매출 신기록 복귀: 4Q25 $96.8M → 1Q26 $88M(OSAT 차질로 역성장) → 2Q26 $99.2M (YoY +22%, QoQ +13%). 1Q 가이던스였던 "QoQ +11%(중간값)"를 실제 +13%로 상회, 공급 차질 회복이 말대로 이행됨.
  • 로열티 급증: 1Q26 $69.6M → 2Q26 $84.2M (+21% QoQ). 다만 3Q 가이던스는 $69~75M으로 재차 정상화 전제.
  • EPS 가속: 1Q26 순이익 $69.3M → 2Q26 $84.4M, EPS $0.77 (YoY +24%, QoQ +21%).

가이던스

  • 분기 매출 가이던스 레벨업: 2Q 가이던스 $192~198M → 3Q 가이던스 $210~216M (중간값 기준 약 +9%). 영업이익 가이던스도 $78~88M → $91~101M.
  • 제품 매출 성장률 가이던스의 질 변화: 1Q26 시점 "2Q +11%, 이후에도 분기마다 성장" → 최신 "3분기도 YoY 약 20% 성장을 예상하며, 하반기가 상반기보다 강할 것" — 'QoQ 회복' 서사에서 '2분기 연속 YoY 20% 성장' 서사로 전환. 3Q 제품 매출 가이던스 $110~116M은 QoQ +14%로 2Q 회복 속도보다 오히려 빠름.
  • 서버 시장 성장률 가정 상향 (3분기 연속): 4Q25 노트 "보수적으로 가트너의 8%" → 1Q26 "10% 초반 성장" → 최신 "서버 출하량 전망은 지난 분기 mid~high single digit에서 두 자릿수(Gartner 12%)로 상향". 8% → 12%, 분모 자체가 커지는 중.
  • 공시 체계 변경: licensing billings 지표 공시를 중단하고 ASC 606 매출 기준으로만 제시 — 신임 CFO(Sumeet Gagneja) 부임과 함께 바뀐 첫 분기.

고객사·수주

  • 실리콘 IP 대형 디자인윈 구체화: 이전 분기들은 "Tier 1 고객의 디자인 윈이 이어지고 있다" 수준의 일반론 → 최신은 "미국 Tier 1 하이퍼스케일러의 차세대 __HBM__ IP 디자인윈을 확보"로 고객 유형·제품을 특정. 수익 구조도 "라이선스·멀티 라이선스 구조라, 해당 아키텍처를 쓰는 제품마다 라이선스 기회가 생긴다"며 반복 매출 가능성 언급.
  • CXMT 관계 첫 언급: "메모리를 만드는 모든 회사는 Rambus와 라이선스 계약을 맺어야 하며, CXMT도 그중 하나다. CXMT의 성장은 Rambus에도 장기적으로 긍정적" — 중국 메모리 부상을 로열티 기회로 프레이밍.

수요·리드타임

  • 가시성에 대한 톤 격상: 1Q26 "수요에는 문제가 없고" (방어적 톤) → 최신 "에이전틱 AI의 CPU 수요 덕분에 확신이 커지고 있다". 실리콘 IP도 1Q26 "연 10~15% 성장… 예상" → 최신 "연 10~15% 성장 전망을 유지하며, 이에 대한 확신은 오히려 커지고 있다".
  • 공급 제약 하 수주 충족 확인: 4Q25에는 OSAT 차질로 "10백만 달러대 초반(low double-digit $M)" 매출 손실 → 최신 Q&A에서 "생산능력 문제로 대응하지 못한 주문이 있었나? — 없었다". 공급 리스크 전망("2027년까지 타이트")은 동일하나, 실제 집행에서는 문제 없음이 확인됨.
  • 전략적 재고 확대 지속·가속: 3Q25 +$6M → 1Q26 +$14M → 최신 +$16M, "3~4분기와 내년 초 램프가 예상되는 핵심 제품 위주". 고객단은 "고객사 재고 축적 징후는 없다"로 과잉주문 리스크 부인(이전 분기들과 일관).

마진·비용

  • FCF 둔화 (재고 투자 영향): 4Q25 FCF $91.2M → 1Q26 $66.3M → 2Q26 $49M (영업현금흐름 $99.8M → $83M → $61M). 매출이 사상 최대인데 현금흐름은 역행 — 전략적 재고 축적과 램프 대비가 원인으로, 의도된 둔화.
  • 제품 GPM 서술 미세 하향: 4Q25 "2026년에도 61~63%를 예상" → 최신 "최근 60~63% 수준에서 운영" + "장기 모델 60~65%는 유효하다". 하단이 61→60으로 내려왔고, 점유율 확대 전략과 마진의 트레이드오프 질문이 처음 등장(회사는 "연간 기준으로 봐달라"로 방어).
  • OPEX 증가 추세: 4Q25 $64.9M → 1Q26 $69.9M → 2Q26 $73.5M (SG&A 증가).

신제품·기술

  • 신제품 비중 목표 상향 경로 유지·구체화: 1Q26 "10% 초반 → 연말 10% 중반" → 최신 "low double-digit % → 4분기 말 mid double-digit %를 목표". 비중 수준은 연속선상이나, "고객 인증 과정을 거쳐야 해서 계단식 증가는 아니다"라는 램프 성격 설명 추가.
  • DDR5 9600 풀라인업 출시 (클라이언트 신규): 이전 분기 "2026년 클라이언트 매출 기여는 여전히 미미할 전망"이라는 언급 수준 → 최신 "__DDR5 9600__ 클라이언트(AI PC)·서버용 칩셋 풀라인업을 출시. 서버용은 __6세대 RCD__와 __PMIC5030__ 기반" — 제품이 실체화.
  • PCIe 7.0 Switch IP 신규 출시: 이전에는 PCIe 7.0 '컨트롤러·수주' 언급 → 최신은 "차세대 AI scale-up/scale-out용 __PCIe 7.0 Switch IP__(128GT/s)를 출시했다. 라이선스 구조라 매출은 향후 몇 분기 안에 빠르게 인식" — 매출 인식 시점이 가까워짐.
  • MRDIMM 톤은 오히려 신중해짐: 3Q25 "장기적으로 DDR5와 비슷한 점유율이 가능하다고 봅니다" → 최신 "의미 있는 기회로 보지만 플랫폼 채택률과 RDIMM 대비 비중은 아직 예단하지 않겠다". 타임라인(4Q 초기 출하 미미, 2027년 본격 기여)은 전 분기와 동일.

리스크 언급

  • 공급 제약은 상수화, 단 성격 변화: 4Q25 "2026년은 수요보다 공급이 제약 요인" → 1Q26 "후공정 공급 부족은 개선되지 않았고 2027년까지 타이트" → 최신도 "공급 제약은 2027년까지 이어질 것"으로 동일하나, "공급사와의 관계가 탄탄해 현재 수요에는 대응하고 있다"로 실제 피해는 부인 — 리스크가 '현재형 피해'에서 '관리 중인 전망 리스크'로 이동.
  • OSAT 품질 이슈 소멸: 4Q25~1Q26 두 분기 연속 주요 주제였던 공급 차질이 최신 콜에서는 언급 자체가 사라짐.
  • 연간 가이던스 미제시 유지: "플랫폼 램프 시점과 공급 제약 때문에 가이던스는 계속 분기 단위로만 제시" — 수요 확신과 별개로 연간 커밋은 피하는 스탠스 지속.

종합 인사이트

최신 분기는 1Q26 OSAT 차질이 '일회성'이었다는 회사 주장이 숫자로 검증된 분기다 — 제품 매출이 가이던스(+11%)를 넘는 +13%로 회복하고 사상 최대를 경신했으며, 3Q 가이던스는 QoQ +14%로 가속을 가리킨다. 서버 시장 성장률 가정이 세 분기 만에 8% → 10% 초반 → 12%로 계단식 상향된 것과 "확신이 커지고 있다"는 표현의 반복 등장은 에이전틱 AI발 CPU 서버 수요가 전망치가 아니라 실수요로 확인되고 있음을 시사한다. 하이퍼스케일러 HBM IP 디자인윈과 PCIe 7.0 Switch IP 출시로 실리콘 IP도 성장의 두 번째 축으로 구체화되는 중이다. 다만 확신 수준은 '수요'에 국한되며, MRDIMM 채택률은 오히려 더 신중해졌고 연간 가이던스도 여전히 거부하고 있어 공급(후공정, 2027년까지)과 플랫폼 지연이 실질 병목이라는 판단이다. 재고 축적에 따른 FCF 둔화($91M → $49M)와 GPM 하단 하향(61% → 60%)은 점유율·램프 우선 전략의 의도된 비용이지만, 램프가 지연될 경우 재고 리스크로 전환될 수 있는 지점이다.
