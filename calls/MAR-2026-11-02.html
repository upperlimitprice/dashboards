MAR — 최신 분기 변화 분석

비교 분기: 2026-02-10 · 2026-05-06 · 2026-08-03 · 2026-11-02 · 최신 분기 기준 수치·톤·확신 표현의 변화 (원문 인용 포함)

종합 인사이트

  • 업황 방향: 글로벌 RevPAR +1.9%(4Q25)→+6.5%(3Q26)로 분기마다 가속, 미국·캐나다가 보합→+7.4%로 반전되며 전 체인스케일 동반 강세임
  • 회사 상황: 연간 가이던스를 3개 분기 연속 상향(RevPAR +1.5~2.5%→+4.5~5%, EPS +13~15%→+20~21%)한 '상향 사이클' 한가운데 있음
  • 확신 수준: 2027년을 "예단하기 이르나"(2Q)에서 예비 가이던스 +3.5~4.5% 공식 제시(3Q)로 전환 — 가시성에 대한 자신감 뚜렷해짐
  • 리스크 교체: 연중 최대 악재였던 중동이 -43%(2Q)→-12%(3Q)로 소멸 국면, 대신 중화권 소비 부진(보합 전환)이 신규 약점으로 부상함
  • 오너 갈등 완화: 2Q 공개 서한 국면에서 3Q "투명·협력적·건설적" 소통으로 톤 전환, ITR 인센티브 등 실행 단계 진입임
  • 주주환원 확대: 연간 환원 $43억+(4Q25)→$44억+(1Q)→$45억+(2Q)→최소 $48억(3Q)으로 계속 증액임

MAR 3Q FY2026 (2026-11-02) — 이전 3개 분기 대비 변화 분석

매출/이익 실적

  • 글로벌 RevPAR 가속: +1.9%(4Q25) → +4.2%(1Q26) → +3.4%(2Q26) → +6.5%(3Q26) — 연중 최고치
  • 미국·캐나다 완전 반전: 보합(4Q25, 셧다운 영향) → +5%(2Q, "13개 분기 만의 최고") → +7.4%(3Q, 월드컵 제외 +6.2%)
  • 럭셔리 강세 심화: 미국·캐나다 럭셔리 2Q "+9% 이상" → 3Q +12%
  • 셀렉트서비스 추세 확립: 4Q25 "-0.3%, 부진…'K자형' 양극화 지속" → 3Q "+6% 이상으로 3개 분기 연속 견조한 성장" — 하위 소비자 우려가 사실상 해소된 톤
  • IMF 급증: 2Q $2.12억(+6%) → 3Q $1.81억(+22%) — 증가율이 한 자릿수에서 20%대로 점프
  • EPS 증가율 확대: +17%(1Q) → +20%(2Q) → +22%(3Q, $3.02)
  • 중화권 역주행: +6% 가까이(1Q) → +3%(2Q) → 보합(3Q, "소비 부진·태풍 영향") — 유일하게 악화된 지역

가이던스

  • FY26 RevPAR 3연속 상향: +1.5~2.5%(2월) → +2~3%(5월) → +3.0~3.5%(8월) → +4.5~5%(11월) — 연초 대비 상단 2배
  • 총수수료: +8~10%(2월) → +9~10%(5월) → +11%(8월) → 약 +13%(11월)
  • 조정 EBITDA: +8~10% → +9~11% → +11~12% → 약 +13%
  • 조정 EPS: +13~15% → +14~16% → +16~18% → +20~21%
  • 2027년 예비 전망 첫 제시: 2Q "2027년은 예단하기 이르나… 견조한 성장 가능성에 낙관적" → 3Q "2027년 예비 전망 +3.5~4.5% 제시(월드컵 역기저를 EMEA 기저 효과가 상쇄)" — 전망을 숫자로 확정한 확신 상승
  • 레지덴셜 브랜딩 수수료: +40%(2월) → +45~50%(5월) → +55~65%(8월) → +90% 이상(11월)
  • 주주환원: $43억+ → $44억+ → $45억+ → 최소 $48억

고객사·수주

  • 파이프라인 확대 지속: 61.0만 실(4Q25) → 61.8만(1Q) → 62.9만(2Q) → 63.4만 실 이상(3Q), 9개월 누적 오가닉 계약 사상 최대
  • Bonvoy 회원 가속: 2.71억(4Q25) → 2.83억(1Q) → 2.95억(2Q) → 3.09억 명(3Q) — 분기당 +1,200~1,400만 명 페이스
  • 미드스케일 확장: 450개+(4Q25) → 500개(1Q) → 약 600개(3Q)
  • 코브랜드 카드 계약 완결→반영: 4Q25 "진행 중…가이던스 미반영" → 1Q "연내 체결 예상" → 2Q 체결 완료(2026년 $30M, 2028년까지 $100~125M) → 3Q는 수수료 +14% 성장의 견인 요인으로 실적에 반영
  • 중동 신규 수주 재개: 3Q "라스알카이마에서 신규 3건 계약 체결 등 오너 투자 의지는 견고" — 분쟁 지역에서도 수주 복원 확인

수요·리드타임

  • 중동 수요 회복 국면 진입: 1Q "3월 중동 RevPAR -30% 이상…연말까지 영향 지속 가정" → 2Q 실적 -43% → 3Q -12%("2분기 -40% 대비 크게 개선")
  • 미국 수요 톤 격상: 4Q25 "'순항 중'…상·하단 양극화는 지속" → 3Q "전 세그먼트에 대해 긍정적이고 추세 지속 예상", "레저가 최강 세그먼트이며 그룹도 강세"
  • 신축 착공 회복 신호 신규: 3Q "미국·캐나다 신축 착공은 작년 +7%에 이어 올해 9개월 누적 +20%로 개선 추세" — 이전 분기까지 없던 선행 지표
  • BT는 요금 주도 성장: 1Q "+1%(ADR +3%, 객실수 -2%)" → 3Q "약 +4%로 주로 요금 상승이 견인…대·중·소기업 전반에 걸쳐 견조"

Capex

  • 키머니 '뉴노멀' 논쟁 등장: 4Q25 "계약 건당 키머니는 2019년보다 낮고 2024년과 비슷" → 3Q는 키머니 $5~6억이 뉴노멀인지 질문받고, 키머니 딜의 객실당 가치 프리미엄 "2025년 약 65% → 올해 누적 약 75%"로 방어 — 규모 자체는 기정사실화
  • 지출 믹스 전환 예고: 4Q25 "테크 35~40%/계약투자 35~40%" → 3Q "키머니 40~45%, 기술 25~30%…내년에도 계약취득비용은 증가, 기술(DTT) 지출은 다소 감소 전망" — 투자 무게중심이 기술→계약 획득으로 이동

마진·비용

  • G&A 통제 강화: FY26 가이던스 +1~3%(연초~2Q) → +1~2%(3Q), 3Q 실제 "+2%에 그침"
  • 오너 양보 비용 본격 반영: 2Q ITR 인센티브 신설("객실 총매출의 최대 50bp 수수료 환급, Marriott가 부담") → 3Q부터 로열티 차지아웃 요율 인하·리뎀션 보상 강화와 함께 실제 비용으로 가동 — 오너 경제성 개선이 일회성 발표에서 상시 비용 구조로 전환

신제품·기술

  • 기술 전환 속도 3배: 1Q "1,000번째 호텔 전환 완료" → 2Q "미주 셀렉트서비스 2,000개+ 호텔" → 3Q "3,000개 이상 호텔 전환 완료, 2027년까지 전개 지속"
  • AI 평가의 구체화: 4Q25 "극초기 단계('선수 주차장에 막 도착한 수준')" → 3Q "AI는 현재 주로 '여행 탐색(discovery)'을 재편 중이며 예약 단계 영향은 더딤…플랫폼들의 수익화는 예약 수수료보다 전통적 광고 쪽에 가까워, 오너에게 경제적으로 유리할 가능성" — 막연한 탐색에서 유통 경제성 판단으로 진전

리스크 언급

  • 중동: 최대 리스크에서 소멸 국면으로: 1Q "연간 글로벌 RevPAR에 100~125bp 부담 가정" → 2Q "약 -100bp로 축소" → 3Q는 비중 축소 논리로 전환("글로벌 오픈 객실의 3%, 파이프라인의 6%, 수수료의 약 3%에 불과…점진적 회복 전망")
  • 중화권: 신규 약점으로 부상: 4Q25 "+3%(ADR 주도, 성장 전환)"로 긍정적 → 3Q "RevPAR이 마이너스에서 보합으로 전환…전반적 소비 심리 둔화로 성장 환경은 어려움"
  • 오너 갈등 톤 완화: 2Q 공개 서한에 "공식 답변은 오너와의 사안이라 비공개" → 3Q "오너와의 소통은 투명·협력적·건설적…'큰 한 방 발표'보다는 매일의 실행으로 오너 수익성을 높이는 데 집중"
  • 4Q 역기저 리스크 신규 명시: 3Q "EMEA는 중동 역기저(전년 대형 이벤트)와 사우디 행사 취소로 RevPAR 감소 예상" — 전 분기까지 없던 구체적 하방 요인
  • 정부 수요 리스크 소멸: 4Q25 "43일간 정부 셧다운으로 정부 수요 RevPAR -30%+" → 3Q에서는 정부 수요 관련 언급 자체가 사라짐
