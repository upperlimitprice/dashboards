6. 프리뷰 해설

MSFT 어닝 프리뷰 — 비트는 기정사실, 관건은 Azure 가이던스 (2026-10-28 AMC)

요약 3줄

  • 12분기 연속 EPS 비트 이력에 직전 분기 +11.8% 서프라이즈까지, 모델 P(beat) 95% — 컨센(EPS $4.72, 매출 $906억) 상회 가능성 매우 높음.
  • 그러나 비트 12회 중 익일 상승은 5회(41.7%)뿐, 평균 반응 -0.1%·중앙값 -1.9% — 실적 자체보다 Azure 성장률·CapEx 가이던스가 주가를 결정해온 종목.
  • 예상 방향 중립(기대반응 -0.4%), 범위 -4.3%~+3.5% — 옵션 IV가 아닌 과거 |반응| 분포 기반 프록시.

발표 개요·컨센서스

  • 발표: 2026-10-28 장마감 후(AMC) (시간은 관례 추정)

컨센 대비 예상 (근거)

  • 계량: 전체 12분기·최근 4분기 모두 비트(비트율 100%) → P(beat) 95%. EPS 서프라이즈는 +0.7%~+12.8% 분포, 직전 분기 +11.8%로 추세도 상방.
  • 정성 (아카이브): Azure 39% 성장에 "수요가 공급을 초과" 지속, M365 Copilot 유료좌석 1,500만석(+160% YoY), 상업 RPO 급증으로 매출 가시성 높음. FY26 전체 영업마진은 "소폭 상승"으로 가이던스 상향 (software/global/uscall/MSFT.md, FY26 Q1·Q2 컨콜 노트)
  • 웰스파고도 비용 절감 조치가 영업마진 개선으로 이어질 수 있다고 코멘트 (JSON IB, 2026-10-27)
  • 단, 아카이브 컨콜 노트는 FY26 Q2(4월 발표)분까지만 있어 직전 7월 콜의 가이던스 세부는 아카이브에 없음.
